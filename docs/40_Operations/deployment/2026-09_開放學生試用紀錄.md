# 開放學生試用紀錄（2026-09）

## 結論

FocusFlow 自 **2026-09-21 起**在 `https://focusflow.ntub.edu.tw` 開放學生試用。對外口徑是「開放學生試用」，**不是「正式上線」**。

| 項目 | 內容 |
|---|---|
| 開放時間 | 2026-09-21 起（試用對象尚未記錄，補上後更新本表） |
| 網址 | 學生／教師 `https://focusflow.ntub.edu.tw/login`；管理員 `https://focusflow.ntub.edu.tw/admin` |
| 帳號來源 | 學生：教師以 CSV 匯入（初始密碼為學號）或自行註冊後由教師加入課程；教師：管理員建立；管理員：不開放註冊 |
| 部署方式 | push `main` → GitHub Actions self-hosted runner 自動部署（見 [CLAUDE.md](../../../CLAUDE.md)「部署與對外連線」） |

## 試用期的使用限制

| 限制 | 預設值 | 設定 |
|---|---|---|
| 學生每日提問次數 | 5 次（台灣時間；網頁與 LINE 合併；失敗不計） | `QA_DAILY_ASK_LIMIT_PER_STUDENT` |
| 單題字數 | 50 字 | `QA_MAX_QUESTION_LENGTH` |
| 登入失敗鎖定 | 同一 Email 15 分鐘內 5 次，鎖 15 分鐘（記憶體計數，backend 重啟歸零） | `LOGIN_MAX_FAILED_ATTEMPTS` 等 |
| 內容可見範圍 | 學生只看得到 active Enrollment ∩ published Course | — |

VM 上的實際值以 VM 的 `backend/.env` 為準，repo 的 `.env.example` 只代表預設值。

## 開放時的對外狀態（2026-09-23 從校外唯讀檢查）

| 項目 | 結果 | 檢查方式 |
|---|---|---|
| HTTPS 憑證 | ✅ Let's Encrypt 正式憑證，效期至 2026-12-09 | 見 [憑證申請紀錄](2026-09-10_Lets_Encrypt憑證申請紀錄.md) |
| HSTS | ✅ 回應帶 `Strict-Transport-Security: max-age=31536000` | `curl -D -` |
| CORS | ✅ 已收斂：`Origin: https://example.com` 的預檢請求不回 `Access-Control-Allow-Origin`；`https://focusflow.ntub.edu.tw` 會回 | `curl -X OPTIONS` 對 `/api/v1/auth/login` |
| port 80 | ❌ 對外不通（學校不開放） | `curl http://focusflow.ntub.edu.tw/` 連線失敗 |
| `/health` | 未經 nginx 轉發，從外部打會拿到前端 HTML | 需在 VM 內 `curl localhost:4000/health`，或看管理員「系統服務」頁 |

## 不影響試用、但仍未完成的項目

- **學生試用驗收證據**：附錄 I 的 12＋2 題正式證據與 shared Atlas 唯讀 runner 持續進行中，見 [學生試用版後端整合文件](../../30_Features/Student_Pilot_Backend/README.md)。
- **LINE webhook 仍走 ngrok**（VM 上的 `ngrok.service`）。是否改用 `https://focusflow.ntub.edu.tw/api/v1/line/webhook` 需先與指導教授討論，改之前要做一次 live 測試。
- **憑證自動續約尚未實際發生**：第一次預計在 2026-11-10 前後，需在 2026-11-15 前確認。
- **port 80**：學校不開放，對外一律提供 `https://` 網址。
- 整站 CSP 尚未加（YouTube iframe 與外部字型需另行測試）。

## 試用期觀察工具

- 使用統計：`npm run report:pilot-usage -- [--from YYYY-MM-DD] [--to YYYY-MM-DD]`（唯讀，只輸出彙總數字，預設排除 demo 帳號）
- 問題回報：學生從畫面右下角「回報問題」送出，管理員在「問題回報」頁處理
- 服務狀態：管理員總覽的「系統服務」（`GET /api/v1/admin/system-status`）
