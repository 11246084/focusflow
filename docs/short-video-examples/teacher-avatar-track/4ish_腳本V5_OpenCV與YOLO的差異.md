## 2. 全域設定

- **影片主題**：OpenCV 與 YOLO 的差異
- **核心事件**：多數人以為兩個工具是「弱的/強的」比較關係，其實差異在於運算資源需求與任務適配
- **核心觀點**：選哪個工具不是比誰強，是看設備（有沒有 GPU）跟任務需求
- **觀眾原本可能以為**：YOLO 比較強，能用就該用 YOLO
- **觀眾看完後應該發現**：YOLO 沒 GPU 幾乎跑不動；工具選擇要看任務，不是看誰厲害
- **目標受眾**：學過或正在學影像處理／電腦視覺基礎的人
- **影片長度**：30 秒
- **影片語氣**：知識解說

## 3. 寫作順序：動筆前的 4 題

1. 我要讓觀眾「想知道什麼」？→ OpenCV 跟 YOLO 到底差在哪
2. 我要故意延後哪個答案？→ YOLO 的 CPU 版本「聽起來可行」但其實不能用
3. 中途最大的反轉是什麼？→ 越強的工具不代表該用；工具各有用途，不是比誰厲害
4. 最後觀眾應該記住哪一句話？→「怎麼選，不是比誰強，是看你的設備跟任務」

## 4. 視覺概念：兩種光的形態

沿用「上 2/3 B-roll＋下 1/3 教師數位分身」分層，B-roll 換成新的視覺隱喻，對應「輕量 vs 重量級」：

```
S1  一個小巧、靈活閃動的光點            =  OpenCV（輕量，CPU 可跑）
     ↓
S2  一個龐大厚重的光體，周圍有能量導管餵入 =  YOLO（強大，但需要 GPU 大量供能）
     ↓
S3  兩個光體並列，各自安穩發光，同等亮度   =  工具各有用途，不是誰壓過誰
```

**為什麼用這個隱喻**：這支片的核心是「兩種不同體質的工具，各自適合不同場合」。光點的靈巧感對應 CPU 輕量運算，光體的厚重感與能量導管對應 GPU 依賴，最後並列同等發光直接呼應核心結論「不是比誰強」。

## 7. 教師數位分身生成規格（依 MiniMax H3 官方教學）

| 項目 | 內容 |
|---|---|
| 生成模式 | **全能參考**（H3 沒有「Reference-to-Video」這個模式名稱） |
| 素材標記 | Prompt 開頭必須逐一交代每份素材用途，例：「@Image1 是人物外觀參考，保留臉部、短髮、原服裝特徵，不新增其他人物」「@Video1 只提供頭部動態節奏，不沿用原場景」 |
| 單次長度限制 | **官方規格 5–15 秒／次**，無法一次生成 30 秒，**改成生成 3–4 段 5–8 秒素材，後製拼接**成下 1/3 常駐層；每段 Prompt 都要重申「同一位主角」，降低跨鏡頭變臉風險 |
| **不對嘴** | **H3 沒有「餵外部音檔驅動嘴型對嘴」的功能**。教師分身全程**嘴巴自然閉合、不說話**——Prompt 需明寫「人物全程不說話、嘴巴自然閉合」，避免「對著鏡頭講述」這類會觸發張嘴動作的描述，改安排點頭、傾聽、手勢等自然動作。實際旁白**完全靠後製疊上零樣本語音複製的音軌**，不依賴分身對嘴，也不用 H3 的原生語音生成 |
| 素材數量 | 官方全能參考最多 9 圖＋3 影片＋3 音訊、合計 12 個檔案，但**先用 2–4 份素材測試**（本稿：臉部圖 1 張 + 動態影片 1 段），別一次放滿 |
| 輸出需求 | 透明背景或綠幕（**開拍前必須實測確認**，這是硬條件） |
| 驗收順序 | 依官方 6 步驟：**主體→動作→鏡頭→聲音→商業細節**，一次只改一類問題，不要同時重寫多項 |

**5 個常見失敗與修改方式**（沿用官方教學）：

| 問題 | 常見原因 | 優先修改方式 |
|---|---|---|
| 人物跨鏡頭變臉 | 切鏡太多，或沒有重申同一人物 | 減少鏡頭數；每次切鏡都重寫「同一位主角」 |

## 10. 合成指令

```bash
# ① 教師分身去背（若平台只給綠幕，逐段處理）
ffmpeg -i avatar_seg1_green.mov -filter_complex \
"chromakey=0x00FF00:0.18:0.05[fg]" -c:v qtrle avatar_seg1_alpha.mov -y
# 依此類推處理 seg2、seg3、seg4

# ② 拼接教師分身各段，成為完整常駐層
ffmpeg -f concat -safe 0 -i avatar_segments_list.txt -c:v qtrle -an avatar_full_alpha.mov -y

# ③ B-roll 拼接（list.txt 依序列出 S1/S2/S3 各片段）
ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -crf 20 -preset medium -an broll_joined.mp4

# ④ 教師分身疊加在下 1/3
ffmpeg -i broll_joined.mp4 -i avatar_full_alpha.mov -filter_complex \
"[1:v]scale=1080:640[avatar];[0:v][avatar]overlay=0:1280:format=auto" \
-c:v libx264 -crf 18 -an composite.mp4 -y

# ⑤ 疊旁白與配樂
ffmpeg -i composite.mp4 -i narration.wav -i bgm.wav -filter_complex \
"[1:a]volume=1.0[v];[2:a]volume=0.12[m];[v][m]amix=inputs=2:duration=first[a]" \
-map 0:v -map "[a]" -c:v libx264 -crf 20 -c:a aac with_audio.mp4 -y

# ⑥ 燒字幕
ffmpeg -i with_audio.mp4 -vf "ass=script.ass" -c:a copy subtitled.mp4

# ⑦ 疊揭露標示（必做，全片常駐）
ffmpeg -i subtitled.mp4 -vf \
"drawtext=fontfile=NotoSansTC-Regular.otf:text='AI 合成影像・經本人授權':\
x=w-tw-28:y=28:fontsize=30:fontcolor=white@0.78:\
box=1:boxcolor=black@0.35:boxborderw=10" \
-c:a copy final.mp4
```

輸出規格：`1080×1920 / H.264 / CRF 20 / 30fps / AAC 128k / faststart`
