### 0.3 R2 的依據：PR 編號反查風險評估（2026-11-01 實測）

| 測試 | 結果 | 結論 |
|---|---|---|
| repo 是否公開 | 公開（GitHub API 未登入即可讀取） | 任何人都能看到 PR、commit 與帳號 |
| 只用產品名搜尋 GitHub（FocusFlow） | 上千筆，本 repo 不在第一頁 | 產品名本身風險低 |
| 用 PR 標題中的技術詞搜尋（例如「Parent Search」＋「Phase 2-2」） | **本 repo 出現在第一頁** | 照抄 PR 標題、描述或截圖文字，就能反查到 repo |
| repo 擁有者帳號 | 帳號名稱就是學號 | 反查到 repo 即可推知參賽單位 |

**判定**：PR 編號單獨出現風險低，但「PR 編號＋原文標題或內容」可被反查，所以依 R2 對外全面改用 E 編號，且任何 GitHub 畫面截圖都不放（截圖裡的文字一樣可搜尋）。Notion 公開站同理：頁面網址含個人名稱，頁面文字可能被搜尋引擎收錄。

> 補充建議（是否採行由團隊決定，我不會動 GitHub 設定）：決賽期間把 repo 暫時改為私有，可再降低反查風險；但這會影響其他已公開引用的連結，需要組長評估。

1. **主畫面**：右下角小型證據標籤（例：`E10`），18px、次要文字色。
