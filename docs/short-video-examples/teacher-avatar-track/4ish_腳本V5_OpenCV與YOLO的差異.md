## 2. 全域設定

- **影片主題**：OpenCV 與 YOLO 的差異
- **核心事件**：多數人以為兩個工具是「弱的/強的」比較關係，其實差異在於運算資源需求與任務適配
- **核心觀點**：選哪個工具不是比誰強，是看設備（有沒有 GPU）跟任務需求
- **觀眾原本可能以為**：YOLO 比較強，能用就該用 YOLO
- **觀眾看完後應該發現**：YOLO 沒 GPU 幾乎跑不動；工具選擇要看任務，不是看誰厲害
- **目標受眾**：學過或正在學影像處理／電腦視覺基礎的人
- **影片長度**：30 秒
- **影片語氣**：知識解說

---

## 3. 寫作順序：動筆前的 4 題

1. 我要讓觀眾「想知道什麼」？→ OpenCV 跟 YOLO 到底差在哪
2. 我要故意延後哪個答案？→ YOLO 的 CPU 版本「聽起來可行」但其實不能用
3. 中途最大的反轉是什麼？→ 越強的工具不代表該用；工具各有用途，不是比誰厲害
4. 最後觀眾應該記住哪一句話？→「怎麼選，不是比誰強，是看你的設備跟任務」

## 4. 視覺概念：兩種光的形態

沿用「上 2/3 B-roll＋下 1/3 教師數位分身」分層，B-roll 換成新的視覺隱喻，對應「輕量 vs 重量級」：

```
S1  一個小巧、靈活閃動的光點            =  OpenCV（輕量，CPU 可跑）
     ↓
S2  一個龐大厚重的光體，周圍有能量導管餵入 =  YOLO（強大，但需要 GPU 大量供能）
     ↓
S3  兩個光體並列，各自安穩發光，同等亮度   =  工具各有用途，不是誰壓過誰
```

**為什麼用這個隱喻**：這支片的核心不是「拆解」（V3）也不是「規模膨脹」（V4），是「兩種不同體質的工具，各自適合不同場合」。光點的靈巧感對應 CPU 輕量運算，光體的厚重感與能量導管對應 GPU 依賴，最後並列同等發光直接呼應核心結論「不是比誰強」。
