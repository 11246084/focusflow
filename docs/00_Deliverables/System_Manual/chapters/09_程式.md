## 9-2 其他附屬之各種元件

### 技術性保護元件

- **JWT 與 RBAC：**`authenticate()` 驗證 token 後重新查詢 active User；route 使用 `authorizeRoles()`。密碼僅存 bcrypt hash，public mapper 不回傳 hash 或 LINE ID。
- **輸入與錯誤回應：**controller 驗證基本格式與 ObjectId；service 拋出具 HTTP status／code 的 `AppError`，統一回傳 `success`、`message`、`data` 或 error code。對外錯誤不應曝露 stack、Mongo query 或 secret。
- **檔案與 avatar：**Multer 限制影片上傳；avatar 僅接受 JPEG／PNG／WebP，二進位存 `avatars` collection，避免每次 User 查詢攜帶圖片資料。
- **通知與快取：**完成影片 fanout 以 dedupe index 支援重送；FAQ cache 命中前會再次確認引用仍位於目前 allowlist，失效即回正式 retrieval。

### 尚不可誤稱為完成的元件

- Parent hierarchy 的 artifact、schema、uploader 與 backend adapter 已存在，但 `HIERARCHICAL_RETRIEVAL_ENABLED` 仍為 false；沒有 active Leaf／Parent、index/filter 和 read-only live E2E 證據，不能宣稱可用。
- `video_segments_video` 的 visual citation path 已有程式與測試；其資料沒有 transcript／caption，不能產生畫面內容答案，也不是正式剪輯或短片發布來源。
- ShortAsset feed／同步／封存、證據化候選與腳本、教師人工成品上傳／審核及 YouTube 發布排程已有程式碼，但 feature gate 預設關閉且真實 YouTube／browser E2E 未於本階段驗收。尚未實作的是由來源影片自動剪輯、9:16 渲染與字幕合成，不應把兩者混為一談。
- 本章未執行完整測試、資料庫寫入、外部 provider、LINE、YouTube 或 VM 操作。程式測試名稱可協助追溯回歸範圍，但不替代上述環境驗收。
