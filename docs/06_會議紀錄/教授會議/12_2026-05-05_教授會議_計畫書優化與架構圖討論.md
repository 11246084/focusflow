## 討論內容

1. LINE Bot + YouTube 影片整合方案

- 背景：需要決定影片播放與互動的最終技術路線。
- 內容：
  - Demo 路線：手動上傳 YouTube → backend 存 youtubeVideoId → STT 處理音訊 → 前端 YT iframe / LINE 傳連結；影片設為 unlisted。
  - 正式路線：FocusFlow 自動上傳，需完成 Google Cloud、YouTube Data API v3、OAuth、refresh token 及 API audit。
  - LINE 內部直接內嵌播放器有技術限制與相容性問題。
- 結論傾向：初期以「帶有精準時間戳的 YouTube 文字連結 + 說明」為主要開發方向，使用者點擊後透過 URL timestamp 參數精準跳轉至對應學習段落；進階影片直接跳轉待後續再完善。

2. 計畫書「技術可行性」章節具象化

- 背景：目前章節描述太空泛，無法說服審查委員系統確實可行。
- 內容：需直接寫明使用的工具與演算法：Gemini Embedding（文本向量化）、Cosine Similarity（相似度比對）、Line Messaging API（通訊介面）。
- 結論傾向：全面從概念化轉為工程化，補齊技術名詞。
