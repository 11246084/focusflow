# 短影音腳本模板・十種呈現手法

- 版本：**v4.0（2026-09-10）**
- 格式：沿用教師數位分身 V4／V5 的結構——手法卡、內容來源、全域設定、寫作四題、視覺架構、8 拍分鏡、旁白、生成／拍攝規格、配樂、字卡、合成、製作順序、驗收、上傳發布
- **每個模板都是空白、不綁題目、可以獨立執行的完整文件**，所有 `【 】` 都是待填佔位符，不需要搭配任何其他文件

> **2026-09-10 改版**：原本的十支是「同一個 Token 觀念、同一組片段，只換拍法」的 A/B 範例，內容寫死在 Token 上，換題目就不能用。現在改成十個模板：保留每種手法獨有的製作知識，拿掉所有綁題目的內容。舊版在 git 歷史裡找得回來。

---

## 怎麼用

1. **先確認題目做得成**：資料庫要有可溯源的片段。系統回答「目前資料庫片段不足以回答這個問題」的題目不能做
2. **挑手法**（見下方「怎麼挑」）
3. **複製那個模板，填完所有 `【 】`**
4. 成品上傳到 FocusFlow 教師「短影片腳本」頁 → 系統以 YouTube 非公開上傳 → 「短影片審核」頁通過後才進學生短影片牆

FocusFlow 自動生成的腳本（教師腳本頁的「複製完整腳本」）目前輸出的是**手法 10** 的格式。

## 怎麼挑

| 你的情況 | 用哪一個 |
|----------|----------|
| 沒預算、要先驗證有沒有用 | 02 或 08（都不用生成） |
| 要衝重播率 | 03 |
| 學生反映「聽不懂」、需要看到過程 | 05 或 08 |
| 學生已上過課，只需複習 | 09 |
| 要大量產出、老師沒空 | 01 或 09 |
| 想拉近師生距離 | 04 |
| 學生一直搞錯同一件事 | 07 |
| 老師講過一段剛好 30 秒講完的內容 | 06 |
| 老師沒空實拍，但希望學生看到、聽到老師 | 10（需書面同意） |
| 觀念太抽象講不動 | 10，或拿掉分身的純隱喻版 |
| 資料庫片段裡找不到「你以為 X，其實不是」的轉折 | 05、06、08、09（鏡04 不需要轉折句） |

## 每個模板裡都有的共用規則

每個模板都已經寫進去，不用另外找：來源等級與查片段的坑、鉤子三種公式、8 拍敘事弧線與留存節奏、唸法標記、自製配樂與混音 −14 LUFS、字型與調色、揭露標示、FocusFlow 上傳與審核流程。

**三道驗證關**

| 關 | 位置 | 檢查什麼 | 不過關 |
|----|------|----------|--------|
| **G1 溯源** | 生成之前 | 每一句都對得回 chunkId，且屬同一課程 | 中止，不花錢 |
| **G2 字面** | 生圖後、生影片後各一次 | 畫面文字 OCR 回讀逐字等於 `expectedText`，且沒有多餘文字 | 重出圖；5 次不過退回程式化字卡 |
| **G3 語音** | 合成或收音之後 | ASR 回讀成品音軌，逐字比對腳本 | 重新合成或重錄 |

**一般性原則**：要動的字用程式化渲染，要跟畫面融為一體的字用生成，兩者不能兼得。收束字卡、公式、多行條列一律程式化。

## 這次拿掉了什麼

| 拿掉的 | 為什麼 |
|--------|--------|
| 寫死 Token 的共用素材、示範句子、分鏡台詞 | 換題目就不能用；改成 `【 】` 佔位符 |
| `_shared-conventions.md` | 內容已拆進每個模板，每個模板都能獨立執行 |
| 舊的 10「抽象隱喻」 | 併入新的 10（抽象隱喻就是分身版的上 2/3；拿掉分身即為原版） |
| 教師數位分身的舊空白模板 | 由 10 取代，並修正三項與 MiniMax H3 官方規格不符的假設：沒有 Reference-to-Video 模式（應為全能參考）、無法一次生成 30 秒（每次 5–15 秒）、不能餵音檔對嘴（分身全程不說話） |
| v5～v8 的層層變更說明 | 只留結論，不留演變過程 |
| 每支的 NT$ 成本 | 沒算 G2／G3 重試與平台費，數字會誤導 |
| 「十種手法 × 三種開場」兩階段 A/B 測試設計 | 那是舊範例的測試計畫，不是模板的內容；要做測試請另立文件 |
