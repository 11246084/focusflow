## 尚存風險與獨立複驗重點

1. 必須讓所有可寫入相關資料的 backend 一起使用新版協定；舊版沒有 intent／heartbeat guard，不能與新版混跑並聲稱有相同保證。本輪沒有查或更改正式 writer、DB 權限或部署設定。
2. `youtubebackups` 預留不自動回收；DB 回應不明／物件刪除後可能留下預留，優先避免錯綁。舊資料已重複的 ID 不自動修正；導入前應另作有授權的唯讀盤點。
3. Mongo 與檔案不是同一 transaction。清理期限採 Mongo 時間加 worker 單調時間，假設時鐘正常前進；host／UPLOAD_DIR 改名或外部直接換檔不在自動恢復保證內。跨 process 的 DB 狀態保護不代表對任意外部檔案工具也有分散式鎖。
4. 上傳 heartbeat 超過 120 秒未成功續寫仍會被隔離，包括程序停止或 DB 長斷線；這時不自動再傳 bytes，遠端可能成功的結果仍需既有隔離收尾。沒有新增管理 UI、HTTP deadline 或重試政策。
5. 課程 cascade 刪除原本沒有 transaction；短片 archive／rollback 碰到清理衝突會回報失敗，可能保留部分封存，不能宣稱整個課程刪除已具原子性。此處保持來源安全，不擴大處理整段 cascade。
6. F3 補回後 completed 重新處理、F4 歷史／管理呈現，以及每日額度 Q-A～Q-F 均未實作。
