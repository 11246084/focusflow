這次會碰到的技術名詞（18 個）

不必懂細節，先認得名字，討論時比較好溝通。

LINE 登入（LINE Login）LINE 官方的授權機制，讓 LINE 證明「這個人是這個 LINE 帳號的主人」。
授權框架（OAuth 2.0）業界標準的授權流程，LINE Login 依此設計。
身分層（OpenID Connect, OIDC）在 OAuth 上加一張身分證明，告訴我們是誰登入。
身分證明（ID Token）LINE 簽發的身分證明；要檢查給誰的、有沒有過期、簽章對不對。
狀態值（state）每次連結產生的一次性亂碼，用來確認回來的是同一個請求。
一次性隨機值（nonce）放進身分證明裡的亂碼，防止舊的證明被拿來重用。
授權碼（Authorization Code）LINE 授權後給的短效代碼，後端拿去換身分證明。
授權碼防攔截（PKCE）Proof Key for Code Exchange，防止授權碼被攔截後冒用。
存取權杖（Access Token）代表授權的憑證；這次用完就丟，不存資料庫。
跨站請求偽造（CSRF）騙使用者在不知情下送出請求，例如點了別人產生的授權連結。
重放攻擊（Replay Attack）把舊的請求或證明再送一次。
競爭條件（Race Condition）兩個請求同時進來，結果和一個一個處理時不同。
唯一索引（Unique Index）資料庫保證同一個值只能出現一次，例如一個 LINE 只能綁一個帳號。
WebhookLINE 有新訊息時，主動通知我們伺服器的網址。
訊息 API（Messaging API）LINE 聊天機器人收發訊息用的介面。
Provider／ChannelLINE 後台的管理單位與一項服務的設定；同一個 provider 底下使用者 ID 相同。
httpOnly Cookie瀏覽器裡程式讀不到的登入憑證，比較不容易被偷。
圖文選單（Rich Menu）LINE 聊天室下方的按鈕選單。
