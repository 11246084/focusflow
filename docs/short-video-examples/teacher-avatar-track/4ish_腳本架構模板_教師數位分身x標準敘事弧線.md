# 🎬 資訊型短影音腳本架構 v1.0（教師數位分身 × 標準敘事弧線）

**這是空白架構模板，不綁定任何主題。填空後即可直接執行。**

> 本模板已經走過 3 支實際腳本驗證（Token／大語言模型／OpenCV vs YOLO），架構本身不用再討論，組員接到這份直接填內容即可。所有 `【 】` 都是待填佔位符。

## 0. 架構決策（固定規則，全組對照，不可自行更改）

| 決策項 | 內容 |
|---|---|
| 敘事結構 | 標準弧線：HOOK→交代→反轉→證據→高潮→結論→收尾（8 拍） |
| 出鏡主體 | 教師數位分身（真人臉＋聲音複製） |
| 生成工具 | ComfyUI + MiniMax H3（含教師數位分身本身、B-roll 都用這條線） |
| 旁白生成 | 零樣本語音複製（用既有語音樣本），**不用** MiniMax H3 原生影音生成 |
| 循環設計 | 不採用（無頭尾接回、無末格=首格等規則） |
| 執行者 | 老師本人操作 ComfyUI/MiniMax H3 |
| 影片長度 | 30 秒 |

**兩項開拍前必須先驗證的硬條件**（尚未確認，每支片都要重新確認一次，因為平台版本可能更新）：
1. MiniMax H3 能否輸出透明背景或綠幕（換背景的前提）
2. MiniMax H3 中文嘴型準不準（**必須用中文口白實測**，不要看英文 demo）

## 1. 視覺架構：教師數位分身 + B-roll（固定規則）

**畫面固定分兩層，全片不變，這是所有主題共用的骨架：**

```
┌─────────────────────┐
│                      │
│   上 2/3｜B-roll     │  ← 依每鏡切換，負責「證明/展示」
│   【本主題的視覺隱喻】 │
│                      │
├─────────────────────┤
│  下 1/3｜教師數位分身  │  ← 全片常駐，固定構圖，只生成一次 30 秒
│  （胸上景，中性背景）  │
└─────────────────────┘
```

- **教師數位分身**：全片固定在下 1/3，構圖不變（胸上景，眼睛在該區塊上 1/3 線），**只生成一次 30 秒**。右上角常駐揭露標示 `AI 合成影像・經本人授權`。
- **B-roll（上 2/3）**：依每一鏡切換，負責「證明/展示」，跟下方口白互補、不重複（上面不要重複下面說的話）。

**每支片開工前先決定 B-roll 視覺隱喻**（三支先例：光帶拆解 / 節點網路擴張 / 兩種光的形態——**新主題要換新隱喻，不要重複用過的**，避免不同影片看起來像換皮）：

〔本主題視覺隱喻｜3 個階段〕
```
S1  【階段一畫面描述】   =  【對應的概念】
     ↓
S2  【階段二畫面描述】   =  【對應的概念】
     ↓
S3  【階段三畫面描述】   =  【對應的概念】
```

## 6. SSML 模板（零樣本語音複製）

```xml
<speak>
  <voice name="[複製聲線]">

    <!-- 1 HOOK -->
    【鏡01口白，用 <break time="300ms"/> 標短停、<break time="500-600ms"/> 標長停】
    <break time="500ms"/>

    <!-- 2 交代 -->
    【鏡02口白】
    <break time="500ms"/>

    <!-- 3 給正解 -->
    【鏡03口白，關鍵詞用 <emphasis level="moderate">關鍵詞</emphasis> 標重音】
    <break time="500ms"/>

    <!-- 4 反轉 -->
    【鏡04口白】
    <break time="500ms"/>

    <!-- 5 證據 -->
    【鏡05口白】
    <break time="500ms"/>

    <!-- 6 高潮 -->
    【鏡06口白】
    <break time="500ms"/>

    <!-- 7 結論 -->
    【鏡07口白】
    <break time="500ms"/>

    <!-- 8 結尾 -->
    【鏡08口白】

  </voice>
</speak>
```

**規則**：
- 英文專有名詞一律用 `<lang xml:lang="en-US">詞</lang>` 包起來，全片發音統一
- 重音全片建議 4–6 個，標太多等於沒標
- 停頓長度不能都用同一個值：短停 300ms、長停 500–600ms

## 8. 旁白：零樣本語音複製處理

```bash
ffmpeg -i 【voice_sample.wav】 -af \
"silenceremove=start_periods=1:start_threshold=-50dB:start_silence=0.05:\
stop_periods=-1:stop_threshold=-50dB:stop_silence=0.1,\
loudnorm=I=-18:TP=-3:LRA=7" \
-ar 48000 -ac 1 voice_sample_clean.wav -y
```

用前先確認樣本底下無配樂（找真靜音段驗證），峰值過高（接近 0dB）要留意削峰風險。

## 9. 配樂與音效

```
A 30-second ambient underscore for an educational short video.
No melody, no drums, no percussion, no vocals, no instruments with clear pitch.
A single sustained warm pad with slow evolving texture.
Dark, spacious, cinematic documentary feel.
Fade in over 1 second, fade out over 1.5 seconds.
```

音效固定三種（開場強調、字卡輕點、切點輕點），規格：

| 用途 | 目標音量 |
|---|---|
| 開場強調 | −22dB |
| 字卡輕點 | −24dB |
| 切點輕點 | −26dB |

混音：旁白 −16 LUFS 基準、配樂 −30 LUFS、成品整體 −14 LUFS，真峰值 ≤ −1 dBTP。

## 11. 合成指令

```bash
# ① 教師分身去背（若平台只給綠幕）
ffmpeg -i avatar_green.mov -filter_complex \
"chromakey=0x00FF00:0.18:0.05[fg]" \
-c:v qtrle avatar_alpha.mov -y

# ② B-roll 拼接（依 list.txt 順序列出 S1~S3 各片段）
ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -crf 20 -preset medium -an broll_joined.mp4

# ③ 教師分身疊加在下 1/3
ffmpeg -i broll_joined.mp4 -i avatar_alpha.mov -filter_complex \
"[1:v]scale=1080:640[avatar];[0:v][avatar]overlay=0:1280:format=auto" \
-c:v libx264 -crf 18 -an composite.mp4 -y

# ④ 疊旁白與配樂
ffmpeg -i composite.mp4 -i narration.wav -i bgm.wav -filter_complex \
"[1:a]volume=1.0[v];[2:a]volume=0.12[m];[v][m]amix=inputs=2:duration=first[a]" \
-map 0:v -map "[a]" -c:v libx264 -crf 20 -c:a aac with_audio.mp4 -y

# ⑤ 燒字幕
ffmpeg -i with_audio.mp4 -vf "ass=script.ass" -c:a copy subtitled.mp4

# ⑥ 疊揭露標示（必做，全片常駐）
ffmpeg -i subtitled.mp4 -vf \
"drawtext=fontfile=NotoSansTC-Regular.otf:text='AI 合成影像・經本人授權':\
x=w-tw-28:y=28:fontsize=30:fontcolor=white@0.78:\
box=1:boxcolor=black@0.35:boxborderw=10" \
-c:a copy final.mp4
```

輸出規格：`1080×1920 / H.264 / CRF 20 / 30fps / AAC 128k / faststart`

## 12. 製作順序

```
① 取得書面同意
      ↓
② 【硬條件驗證】用一小段中文口白實測 MiniMax H3：
   能不能輸出透明背景？中文嘴型準不準？
   → 不過關就整個「教師分身」設計要重新評估工具
      ↓
③ 處理語音樣本（修剪靜音 + loudnorm）
      ↓
④ 零樣本複製 → 合成 30 秒旁白 → 計時、聽關鍵詞唸法
      ↓
⑤ Reference-to-Video 生成教師數位分身 → 一次產出 30 秒 → 確認透明背景 → 裁切至下 1/3
      ↓
⑥ Image-to-Video 生成 S1/S2/S3 B-roll 素材 → 檢查文字是否逐字正確 → 各轉 8 秒無聲影片
      ↓
⑦ 生成配樂與三個音效
      ↓
⑧ 立即下載存檔（生成服務通常只保留 2 天）
      ↓
⑨ B-roll 拼接 → 疊教師分身 → 疊旁白配樂 → 燒字幕 → 疊揭露標示
      ↓
⑩ 聽一次成品：關鍵詞有沒有唸錯
      ↓
⑪ 先以 unlisted 上傳，等 15 分鐘確認無版權聲明，再改可見度
```
