# 管理員介面與教師儀表板重調設計決策

這份文件記錄管理員七個頁面與教師儀表板重調的討論：現況、可用的資料、已定案的方向，以及要逐題定案的問題。它讓接手的人或 AI 不用重讀對話就能接續；整體方向與第一批（教師儀表板）的細部設計已定，可以開始實作。功能是否完成只看[目前狀態](../../current-status.md)。

範圍是管理員的系統總覽、使用者、課程、影片、YouTube 上傳、問題回報、使用統計，以及教師的總覽頁。不含學生端、短影片製作與管理頁（見[短影片決策](../Short_Video/decisions.md)）與對話欄（見[對話功能優化](../QA_Conversation/decisions.md)）。

## 名詞

- **儀表板**：登入後第一眼看到、用來掌握狀況的頁面。這裡指管理員的系統總覽、使用統計，與教師的總覽。
- **洞察**：從學生的提問與觀看紀錄整理出來、能讓教師決定下一步的資訊，例如「這一段很多人問、而且常答不出來」。
- **待辦提醒**：需要這個人動手處理的事，例如處理失敗的影片、等待確認的短影片。
- **答不出來的提問**：系統找不到足夠的課程內容而回覆無法回答的題目，問答紀錄的狀態是 `no_match`。

## 可參考的資源（2026-11-17 查詢）

Weihao 提供了四個資源，另外查了同類的工具。以下依搜尋結果整理，多數來源是整理文章或廠商自己的部落格，沒有逐一打開各專案確認授權與維護狀況；要引進任何一個之前須先查證。

前端目前是手寫 CSS 加設計變數，沒有用 Tailwind。這類工具的主流是「shadcn 加 Tailwind」，所以大部分不能直接安裝，只能參考版面後用自己的元件做。

| 用途 | 資源 | 這次怎麼用 |
|---|---|---|
| 版面怎麼排 | Tremor（數據儀表板元件）、BoardUI（儀表板元件與範本，部分付費）、Shadcn Admin 與 TailAdmin（管理後台範本） | 都建立在 Tailwind 上，不安裝；參考數字卡搭配趨勢、圖表與表格的排法、篩選條件的位置 |
| 轉場動態 | [Transitions.dev](https://github.com/Jakubantalik/transitions.dev)（純 CSS 轉場，免費開源） | 可以直接用，短影片頁改版時已參考過 |
| 篩選、分頁、彈出面板的行為 | Base UI、Radix Primitives、React Aria（只處理鍵盤操作、焦點與無障礙，不附樣式） | 需要時引進 Base UI，外觀照[設計文件](../../../DESIGN.md)自己寫。引進屬於新增套件，實作時再確認 |
| 圖表 | Recharts、Nivo、visx（不依賴 Tailwind 的 React 圖表套件；這一項沒有查證） | 等確定要畫哪些圖再決定。只需要簡單的趨勢線時，優先自己用 SVG 畫，不加套件 |
| 不採用 | Bencho（俏皮的互動小元件與音效）、Magic UI、React Bits（動畫元件） | 儀表板是每天使用的工具頁，重點是看得快，這類效果會干擾 |
| 無法判斷 | Beautiful UI | 只找到一篇文章提到，找不到產品頁 |

不引進 Tailwind：好處要到之後大量做新頁面時才會出現，代價是現在就多一套樣式系統和既有頁面並存。
