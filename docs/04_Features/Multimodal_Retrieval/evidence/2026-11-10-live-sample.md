## 首次失敗與修正

第一筆 query 最初因 SDK 不支援 `auto_truncate` 而失敗。檢查 google-genai 的 Gemini Developer API 轉換器，並用真正 SDK 搭配無網路 transport 重現後，確認此設定會在 HTTP 前拋出 ValueError。前一輪 Fake SDK 沒有覆蓋這個序列化限制。

已移除該參數，保留既有文字與媒體大小限制，新增真正 SDK 的文字／WAV／MP4 序列化回歸。之後在同一筆授權、同一份帳本中續跑原訂 12 個輸入，全部成功。先前預留的 US$0.0016384 保留。

三題文字與聲音首名皆對應預期，畫面為其中兩題，兩版 RRF 首名皆對應預期。B 的畫面 cosine 對自身為 0.549994，排第三。抽查 B 取樣中段是講者鏡頭，可能提供較少自然語言處理／ChatGPT 的視覺線索。這是畫面檢視後的合理解釋，語音訊號由獨立音訊路徑提供。
