# 圖庫

這裡是文件圖檔的單一來源，方便查找成品與原始碼。請依文件與章節選圖，以相對路徑引用，避免另存副本。

## 用途與命名規則

共用圖依種類放在架構圖、研究架構圖與 Logo；手冊專用圖與原始碼放在 `系統手冊/chNN/`，共用工具放 `_shared/`。有原始碼的圖與截圖使用圖說檔名；後續改圖用 `-vX-x`，例如 `圖3-1-1-系統架構圖-v1-1.png`；無原始碼且未確認來源的圖保留原名與所有版本。

例：第 5 章需要使用個案圖 → 在 `系統手冊/ch05/` 找成品與原始碼 → 從章節以相對路徑引用。
