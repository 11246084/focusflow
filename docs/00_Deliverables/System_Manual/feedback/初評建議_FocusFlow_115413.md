# FocusFlow AI 初評建議摘錄

組別：四技第 115413 組。來源：114-2 專題初評建議事項—四技組；整理日期：2026-09-29。

僅摘錄本組評審意見，完整跨組原件保留在學校資料夾。以下是初評當時的意見，不代表目前功能或改善事項已驗收。

## 評審意見 1

1. 說明影片到可被檢索與提問的向量化過程，與中間調較的步驟。
2. 展示如何以「複雜」的提問，進行精準的回答，並能轉跳至特定的影片片段。

## 評審意見 2

1. 評分項目包含個人簡報儀態，除了簡報內容外，也可適度由每位成員分別回復評審問答。
2. 針對非公開的線上教學內容，為防範數位資產外流，可考慮介接 Vimeo 等專業影音串流平台，並啟用「網域層級隱私限制（Domain-Level Privacy）」功能，限制僅能在指定網域內嵌入播放。
3. 建議可切入現行補習班的線上函授與數位學習市場，規劃教育業者的商務合作方案。

## 評審意見 3

1. 商業模式成本及收益請量化評估，以支持系統實踐可行性。
2. 影片存放Youtube 節省空間，沒有授權帳密要如何存取未公開的影片，請再評估。
3. 餘弦相似度計算，影片的這些特徵值如何產生？請補強說明。
4. 圖6-1-2 未見系統提及的Youtube 部份，請修正。
5. 設計類別圖為何完全沒有 method，請重新分析。

各項意見的處理狀態、目前程式／文件證據與待驗收事項，另由團隊確認；本次僅整理來源。
