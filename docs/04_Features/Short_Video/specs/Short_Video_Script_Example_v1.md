# 短影音腳本文件（範例）v1

**文件性質：範例 + 可複製模板。**
本文件示範「一份可以直接交給拍攝的短影音腳本長什麼樣」。上半部（§1–§9）是填好的完整範例，§10 是清空後的空白模板，換題目時直接複製 §10 使用。

- 版本：v1（2026-08-13）
- 影片類型：**真人口播**（有講者出鏡）
- 適用範圍：個人品牌／教學帳號的社群短影音

> ⚠️ 這份文件不適用於 AI 生成的教學短影音。後者請看 [Phase2_Short_Video_Production_Spec_v1.md](Phase2_Short_Video_Production_Spec_v1.md)，該規格的紅線明文禁止畫面出現可辨識人臉與任何文字，與本文件的真人口播完全是兩套做法，不可混用。

## 2. 腳本策略

| 要素 | 本片的處理 |
|------|-----------|
| 鉤子 | 直接點出他後台看得到的數字（兩百），並否定他最可能的歸因（剪輯） |
| 痛點 | 不是「經營很辛苦」，而是「愈剪愈漂亮、數據卻沒動」這個具體落差 |
| 價值 | 一套用後台數據反推腳本缺口的判斷方法 |
| 解方 | 挑一支舊片，把第一句話換成具體數字，重發 |

## 3. 口播稿（142 字／實測 29 秒）

正文不標示要素名稱，四段自然串聯，直接對鏡頭念。

```
你的播放數卡在兩百，問題通常不在剪輯。

你每週固定發片，畫面一支比一支乾淨，數據卻跟上個月長得一模一樣。

其實打開後台就能診斷：播放起不來，是前三秒沒鉤子；
有人點進來卻看不到一半就滑走，是沒講中痛點；
完播還行但沒人收藏，是他沒帶走東西。

今天挑一支舊片，把第一句話整句刪掉，改成一個具體數字，重發一次。
想要我用的那組提示詞，留言「腳本」。
```

**字數是估計值，碼錶才是準的。** 語速慢的人砍到 130 字。

## 4. 分鏡表

畫面 9:16、1080×1920。**上三分之一與下三分之一保持空白**，留給字卡與字幕，人物不佔滿全畫面。

| 時間 | 段落 | 鏡位／景別 | 人物位置 | 運鏡 | 光影 | 畫面／字卡 |
|------|------|-----------|----------|------|------|-----------|
| 0–3s | 鉤子 | 中近景（胸上），等效 35mm | 置中偏右，眼睛落在上三分之一線，頭頂留 8–10% 空隙 | 固定，不推不搖 | 主光左前 45°／高 30°，柔光箱；臉部左亮右暗，明暗比 3:1 | 左側空白處疊「200」大字卡，出現 0.5s 後淡出 |
| 3–10s | 痛點 | 同一鏡位不切 | 不動 | 極慢推近（全片推進約 5%，觀眾不該察覺） | 不變 | 無字卡，只留逐字字幕，讓觀眾看臉 |
| 10–20s | 價值 | 切第二機位，或跳接至偏左 45° 側身 | 移到畫面**左**三分之一，右側整片留白 | 固定 | 加背景光：人物後方 1.5m 外一盞暖色 practical light | 右側依序疊三行，逐行推入、前行不消失：<br>`播放低 → 沒鉤子`<br>`中途滑走 → 沒痛點`<br>`沒收藏 → 沒價值` |
| 20–27s | 解方 | 切回第一鏡位，景別收緊至胸上偏近 | 回到置中偏右 | 固定 | 主光不變，補光板拉近半格，明暗比降到 2:1（語氣轉友善） | 下方字卡：`刪掉第一句 → 換成一個數字` |
| 27–30s | CTA | 同上 | 同上 | 固定，最後 0.5s 定格 | 不變 | 留言框圖示自左下滑入，字卡「留言：腳本」 |

## 5. 燈光配置

三燈配置。最低配可只用主光 + 補光。

```
                    [背景光 暖色]
                          │
                       (背景牆)
                          │  ← 人物離背景 ≥ 1.5m
                       (人物)
                      ╱       ╲
        [主光 45°/高30°]      [反光板 1/4 強度]
             柔光箱                白色
                      ╲       ╱
                      [ 攝影機 ]
```

| 燈位 | 器材 | 位置 | 強度 |
|------|------|------|------|
| 主光 Key | 柔光箱或 60cm 柔光傘 | 人物左前方 45°、高於眼睛 30°、距離 1–1.2m | 基準 |
| 補光 Fill | 白色反光板 | 主光對側 | 主光的 1/4–1/3 |
| 背景光 | 暖色小燈／檯燈 | 人物後方 1.5m 外 | 弱，只為分離層次 |

要點：

- 主光**距離愈近光愈柔**，陰影邊緣愈軟。不要為了怕過曝而把燈拉遠。
- 補光的目的是讓暗部還看得到細節，**不是把臉打平**。
- **人物離背景至少 1.5m**，這是散景的來源，比開大光圈更有效。
- **色溫統一 5000K**，室內燈與窗光不要混用，混色溫在手機上會出現臉一半偏綠。
- 只有自然光時：人物側對窗、窗在左前方 45°，對側放反光板，同樣成立。

## 6. 拍攝參數

| 項目 | 設定 |
|------|------|
| 焦段 | 等效 35mm（近景）／50mm（第二機位）。避免廣角端拍臉變形 |
| 光圈 | f/2.0–f/2.8 |
| 快門 | 1/50（30fps）或 1/100（60fps） |
| 解析度 | 1080×1920 直拍；或 4K 拍攝後裁切，保留二次構圖空間 |
| 收音 | 領夾麥，距嘴 20cm |
| 眼神 | 全程看鏡頭，不看螢幕。提詞貼在鏡頭正上方 |

**手機內建麥克風是這支片最大的風險。** 畫面差觀眾可以忍，聲音差會直接滑走。

## 9. 拍攝前驗收清單

**腳本**
- [ ] 鉤子是具體場景或數字，不是「你是否也有這樣的困擾」
- [ ] 痛點寫成場景，不是抽象形容詞
- [ ] 價值從觀眾能帶走什麼出發，不是創作者想講什麼
- [ ] 解方是今天就能執行的動作，不是「建議你多加強」
- [ ] 行動呼籲**只有一個**
- [ ] 已經對著手機念過一次，卡舌頭的句子都改掉
- [ ] 已經把最平的一句換成自己真實遇過的事

**畫面**
- [ ] 上下三分之一留白，字幕字卡不會蓋到臉
- [ ] 人物離背景 ≥ 1.5m
- [ ] 色溫統一，臉上沒有兩種顏色
- [ ] 眼睛落在上三分之一線

**成品**
- [ ] 總長 25–40 秒
- [ ] 靜音播放能看懂
- [ ] 字幕未被手機 UI 遮擋
- [ ] 收音無環境噪音、無爆音

## 11. 生成腳本用的提示詞

需要用 AI 產第一版時，把 §10.1 的欄位填進下列提示詞。**唯一要改的是「我提供的資訊」那七行，其餘維持原樣。**

```
你是一位擅長短影音行銷策略、觀眾心理與口語文案的專業腳本企劃。
請根據我提供的資訊，撰寫一段約 30 秒的短影音口播腳本。腳本必須依序包含以下四個核心要素：

1. 鉤子：前三秒立刻抓住目標觀眾，讓他意識到「這件事和我有關」。
2. 痛點：說出目標觀眾正在遇到，卻可能不知道該如何清楚描述的具體問題。
3. 價值：明確告訴觀眾，看完這支影片可以獲得什麼實用資訊、成果或改變。
4. 解方：提供一個觀眾今天就能執行的具體方法、步驟或行動。

【我提供的資訊】
主題：
目標觀眾：
觀眾目前遇到的問題：
我想分享的觀點或方法：
希望觀眾獲得的結果：
希望觀眾採取的行動：
產品／服務／品牌資訊（沒有可填「無」）：
希望的語氣：

【腳本要求】
- 使用繁體中文與自然的台灣口語。
- 口播長度控制在約 30 秒。
- 開頭不可使用「你是否也有這樣的困擾」等老套問句。
- 鉤子必須具體、有感，不能只靠誇張或製造焦慮。
- 痛點要像真實生活中的情境，不可只有抽象形容詞。
- 價值要從觀眾的收穫出發，不要只介紹創作者想說什麼。
- 解方必須具體到觀眾看完就知道下一步怎麼做。
- 不使用空泛口號、過度比喻、艱深術語或不自然的廣告腔。
- 句子簡短、節奏明確，方便真人直接對著鏡頭口播。
- 四個要素要自然串聯，不要像在朗讀條列內容。
- 若有設定行動呼籲，結尾自然引導觀眾留言、收藏、分享、追蹤或點擊連結。
- 不可捏造數據、案例、效果或使用者沒有提供的資訊。
- 如果資訊不足以寫出精準腳本，請先提出最多 5 個必要問題，不要自行假設。

請依照以下格式輸出：

【腳本策略】
鉤子：
痛點：
價值：
解方：

【30 秒完整口播稿】
直接提供一段可以拍攝的完整口播內容，不要在正文中標示「鉤子、痛點、價值、解方」。

【備選開場】
另外提供 3 句不同切角的前三秒開場：
1. 結果導向
2. 痛點導向
3. 反常識導向
```

拿到 AI 產出後還有兩件事只有人能做：

1. **念出來計時。** 螢幕上順不代表念得順，用自己的語速量長度比算字數準。
2. **把最平的一句換成自己的東西。** AI 不知道你上週跟客戶的對話、踩過哪個坑，而那正是觀眾記得住你的原因。

## 12. 缺哪一塊會卡在哪一關

數據不好時先查這張表，再決定要不要換題目。

| 腳本缺了什麼 | 卡在哪一關 | 後台會看到的樣子 |
|--------------|-----------|------------------|
| 沒有鉤子 | 曝光 | 播放數起不來，前三秒流失特別陡 |
| 沒有痛點 | 停留 | 有人點進來，但看不到一半就滑走 |
| 沒有價值 | 分享 | 完播還可以，但沒人收藏、沒人轉發 |
| 沒有解方 | 轉換 | 互動數字漂亮，但沒有私訊、沒有點擊 |
