# 🎬 短影音腳本模板 v4.0｜06・原片剪輯＋字幕強化

**不寫新腳本、不生任何畫面、不重新配音——直接從課程原片剪出關鍵那 30 秒，轉 9:16、把字幕做大。聲音 100% 是老師原話。**

**這是空白模板，不綁定任何主題。所有 `【 】` 都是待填佔位符，填完即可獨立執行，不需要搭配任何其他文件。**

|---|---|---|
| `rewritten` | 改寫片段內容，沒有新增資訊 | — |

| `corrected` | 老師原話，只修 STT 聽錯的字 | — |

## 3. 寫作順序：動筆前的 4 題

1. 我要讓觀眾「想知道什麼」？→【＿＿】
2. 我要故意延後哪個答案？→【＿＿】（留到鏡06才揭曉）
3. 中途最大的反轉是什麼？→【＿＿】（**優先從資料庫原句裡找現成的轉折**）
4. 最後觀眾應該記住哪一句話？→【＿＿】（鏡07會再講一次）

**鉤子三種公式**（本手法預設：**反常識（冷開場：把原片裡最反直覺的 2 秒抽到最前面）**）

| 公式 | 做什麼 | 寫法 |
|---|---|---|
| 反常識 | 否定他相信的事 | 「你以為【X】？其實【Y】。」 |
| 錯誤警告 | 指出他正在犯的錯 | 「你在【做某事】，但【某處】可能搞錯了。」 |
| 清單預告 | 預告數量、製造缺口 | 「【主題】有【N】件事，第【N】件多數人不知道。」 |

- 口說鉤子 **3 秒內講完，約 10–14 字**，超過就是寫太長。
- 鉤子要從資料庫找得到的反差來寫，不要為了吸睛講資料庫沒有的話。

## 4. 視覺架構：選段與轉檔

**選段規則（可程式化）**

1. 起點取片段 `startSec − 4`（讓老師講完前一句、氣口自然）
2. 冷開場從該段挑「最反直覺的 2 秒」。可程式化的判準：找逐字稿裡含「其实不是／不对／也是／包含」的最短句
3. 終點取「該 chunk 最後一句的句尾」，**不可切在句中**
4. 總長超過 40 秒就往後砍段，**不可加速播放**
5. 起訖點各留 0.3 秒靜音，避免切到字頭字尾

**什麼時候不能用這個手法**

- 原片有「剛才那張投影片」「你們看螢幕」「我們直接來看他的那個…」這種**指涉畫面**的句子——抽出來就看不懂；終點必須切在指涉句之前
- 原片那段講到一半被學生打斷
- 原片畫質低於 1080p
- **逐字稿錯字多到校正等於重寫**——那就失去這支的意義，不要用這個手法

**轉檔：用模糊背景填滿，不要裁切**（直接裁會把老師或投影片切掉）。主體置中後上下各有約 480px 的模糊帶——**上帶放標題字卡，下帶放字幕**。

## 6. 聲音（老師原音，只有處理空間、沒有設計空間）

| 項目 | 規格 |
|---|---|
| 語氣 | 無法指定，是老師當下的樣子。剪點要落在自然的氣口 |
| 語速 | **不可加速**。一加速聽感就從「講課」變成「趕進度」，口音也會失真 |
| 剪點 | 一律落在氣口，不可切在換氣中間；切點前後各留 0.3 秒 |
| 配樂 | **不加**。原片已有教室環境音（冷氣、翻頁、學生聲），疊配樂會變成兩個空間 |
| 可以做 | HPF 80Hz 濾冷氣低頻；整體 normalize 到 −14 LUFS；**輕度** de-noise |
| 不可以做 | 換配音、補錄漏字、用 AI 修飾語氣。一旦重錄，這支的唯一優勢就沒了 |

冷開場是把原音的一段**搬**到最前面，不是獨立出來重新處理。兩處必須用同一份音檔，否則同一句話在 0 秒與後段聽起來會不一樣。

## 7. 字幕校正規格

**校正只允許改「聽錯的字」**，不可改語序、不可補詞、不可刪句。校正後必須與音檔逐字對得上——判準：關掉畫面、只聽聲音看字幕，每個字都對得起來。

| 允許 | 不允許 |
|---|---|
| 簡體轉繁體 | 改語序 |
| 修 STT 聽錯的字 | 補老師沒講的詞 |
| 刪贅詞（「啊」「那個」「呢」） | 刪整句 |
| 補標點 | 換更專業的用詞 |

**已知 STT 錯字對照表**（同一位老師、同一套 STT，錯字會重複出現，**每做一支就補進來**）

| 逐字稿 | 正確 |
|---|---|
| 济费方式 | 計費方式 |
| 自然与人处理 | 自然語言處理 |
| chat gbd／确诊GPT／雀的gp／切gbt | ChatGPT |
| gymny | Gemini |
| clue | Claude |
| OvenCV／Opens TV | OpenCV |
| 優龍 | YOLO |
| 真側 | 偵測 |
| 像量 | 向量 |
| 【＿＿】 | 【＿＿】 |

**用 G3 把校正變成半自動**

```
① 對原音跑一次 ASR（要與 pipeline 用的不同引擎，否則會犯一樣的錯）
      ↓
② 套上方錯字對照表，自動修掉已知錯誤、簡轉繁
      ↓
③ G3 比對：ASR 結果 vs 校正稿
      → 一致的段落：直接採用
      → 不一致的段落：標記出來，人只看這些
```

專有名詞給 ASR 當 hint 詞表，正確率會明顯提升。**仍然需要人做最後確認**——這是把工作量從「整支」降到「差異處」，不是取消。

## 8. 配樂與音效

**配樂與音效一律自製，不用現成音樂庫。**「免費」和「不會被 Content ID 打」是兩件事——Content ID 比對音訊指紋、不看授權文件。

配樂 Prompt（自製或生成皆可，40 秒可循環）：

```
A 40-second ambient underscore for an educational short video.
No melody, no drums, no percussion, no vocals, no instruments with clear pitch.
A single sustained warm pad with slow evolving texture.
Dark, spacious, cinematic documentary feel.
Seamless loop, dynamics within 3 dB, no sections.
```

| 用途 | 做法 | 目標音量 |
|---|---|---|
| 開場強調 | 60Hz 正弦波 + 0.3 秒指數衰減 | −22dB |
| 字卡輕點 | 2–3ms 短脈衝 + 極短 reverb | −24dB |
| 切點輕點 | 同上，再低 4dB | −26dB |

**本手法的配置**

| 配樂 | 音效（最多 3 種） | 特別注意 |
|---|---|---|
| **無配樂** | 只有冷開場字卡輕點一種 | 原片有教室環境音，加配樂會打架 |

**混音**：旁白 −16 LUFS 基準、配樂 −28～−32 LUFS（旁白出現時再壓 3dB）、音效峰值不超過旁白 −6dB、**成品整體 −14 LUFS，真峰值 ≤ −1 dBTP**。沒做 loudness normalization 的片子會被平台自己壓，聽起來會悶。

- 一支片的音效種類**不超過 3 種**，多了就變綜藝節目。
- **每一個音效都要有對應的視覺事件**。多數人第一次看是靜音的，有聲沒畫面的音效等於白做。
- 禁止：鼓點強烈的 trap／EDM、任何有人聲的音樂、版權不明的流行曲。

## 10. 合成指令

```bash
# ① 截取選段並轉 9:16（模糊背景填滿，不裁切）
ffmpeg -ss 【起始秒】 -to 【結束秒】 -i 【原片檔名】.mp4 -filter_complex \
"[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=24[bg];\
 [0:v]scale=1080:-2[fg];\
 [bg][fg]overlay=(W-w)/2:(H-h)/2" \
-c:a aac vertical.mp4

# ② 冷開場：從同一份檔抽出最反直覺的 2 秒，放大 130%
ffmpeg -ss 【冷開場起】 -to 【冷開場訖】 -i vertical.mp4 -vf "scale=iw*1.3:-2,crop=1080:1920" -c:a aac cold_open.mp4

# ③ 拼接：冷開場＋選段（list.txt）
ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -crf 20 -c:a aac joined.mp4

# ④ 燒校正後字幕與字卡
ffmpeg -i joined.mp4 -vf "ass=script.ass" -c:a copy subtitled.mp4

# ⑤ HPF＋響度標準化（不加速、不重錄）
ffmpeg -i subtitled.mp4 -af "highpass=f=80,loudnorm=I=-14:TP=-1:LRA=7" -c:v copy final.mp4
```

輸出規格：`1080×1920 / H.264 / CRF 20 / 30fps / AAC 128k / faststart`
