# 短影片腳本自動化整合文件

本資料夾集中管理短影片腳本自動化的規格、施工單與驗收證據。

## 這個任務在做什麼

把「學生常問問題 → 短影片」這條路自動化：系統**自動選題**、找證據、生成腳本 → 教師審核 → 教師產出影片並上傳 → 系統**自動上架 YouTube**。

腳本產出的是**結構化資料（JSON）**，不是完整 markdown——模板固定章節不由系統生成。

影片產製（B-roll、語音、合成）、前端頁面、既有腳本範例與模板的修改，不在本輪範圍。

| [施工單](work-orders/2026-09-03_short-script-automation-work-order_v0.1-draft.md) | 工作項拆解、順序、修改位置、測試與停止點 |

## 目前狀態

**兩份文件皆為草案，尚未核准，尚未開工。目前卡在核准關卡 ①。**

| 文件 | 版本 | 狀態 | 下一步 |
|------|------|------|--------|
| 規格書 | v0.9 草案 | 內容完整，簽核欄未填 | 專題負責人核准後升 v1.0 Frozen |
| 施工單 | v0.1 草案 | 內容完整，簽核欄未填 | 待規格書 Frozen 後跑對齊檢查表並核准 |

規格書第 8.2 節列有五項待決事項（P-01～P-05），**五項皆不擋 v1.0 Frozen**，各自擋不同的下游關卡：

| 編號 | 擋什麼 |
|------|--------|
| P-01 同義題分群門檻 | 擋正式產出，不擋實作與驗收（見下方「P-01 的例外」） |
| P-02 腳本品質標準 | 擋開放給教師使用 |
| P-03 書面同意書格式 | **擋上架（本輪已納入）**——上架 API 須要求教師確認 |
| P-04 腳本模板修訂 | 擋套用階段，不擋本功能 |
| P-05 候選來源是否擴到 `questions` | 擋候選完整性，不擋實作 |

P-01 與 P-05 都須由階段 A 的實測資料決定，不憑推論定值。

## 核准流程

本任務沿用[學生試用版施工單目錄說明](../2026-09_Student_Pilot_Backend/work-orders/work-order_README.md)的慣例，不另立一套規則。以下只記錄本任務特有的部分。

### 五個核准關卡

```text
① 規格書 v0.9 草案 → v1.0 Frozen
      核准人：專題負責人（P-02 相關另需指導教授）
      條件：規格書「核准與升版」節的條件表
      ↓
② 施工單 v0.1 草案 → 核准
      核准人：專題負責人 + 實作者
      條件：施工單「核准」節的七項對齊檢查表
      ↓
   實作批次 A（WO-01～WO-04）
      ↓
③ 停止點 SP-1
      核准人：專題負責人
      條件：規格書 7.1 檢查表 + 未觸發明確失敗條件 + P-01 門檻已定版
      ↓
   實作批次 B（WO-05～WO-07）
      ↓
④ 停止點 SP-2
      核准人：專題負責人
      條件：規格書 7.2 檢查表
      ↓
   實作批次 C（WO-08 上架）
      ↓
⑤ 停止點 SP-3
      核准人：專題負責人
      條件：規格書 7.3 檢查表，含實際上傳一支到 YouTube 並確認可播放
```

**三個停止點都需要人核准，不由實作者自行判定。** SP-1 觸發失敗條件時回頭調參數，不得進入批次 B。

### 簽核欄在哪

| 關卡 | 位置 |
|------|------|
| ① 規格書 Frozen | 規格書「核准與升版」節的簽核欄 |
| ② 施工單核准 | 施工單「核准」節的簽核欄 |
| ③④⑤ 停止點 | 證據檔內記錄核准人與日期 |

### P-01 的例外

規格書的 P-01（同義題分群門檻）**不擋任何核准關卡**。它只能靠跑批次 A 拿實際資料才能校準，若列為 Frozen 的前置條件會形成解不開的循環。定位為校準參數：Frozen 時維持預設 `0.85` 並標記未校準，SP-1 時依證據定版並回填規格書附錄 B——此屬參數回填，不觸發規格書退回。詳見規格書 8.2。

### 判斷順序

```text
規格書 > 施工單 > 現有程式碼 > 實作者推論
```

若互相衝突，記錄具體位置、停止該項工作、等待決議，不得自行選擇版本。改變範圍或安全紅線須升版並記入變更紀錄，不得直接改內文。

## 證據保存

驗收證據存入 `evidence/`（尚未建立，SP-1 時再建），命名 `YYYY-MM-DD_<項目>.<副檔名>`。

證據須去識別化：不得包含學生姓名、email 或可辨識身分的原始提問全文；問句預覽比照學生試用版慣例，只保留長度與前 80 字。
