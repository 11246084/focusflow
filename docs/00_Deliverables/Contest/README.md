## 版本管理

- 檔名帶「定稿」的 FinFlow 檔案是 repo 既有版本；本次搬移未變更內容或重新認定送件版本。
- `revisions/` 中的 FinFlow 校正版含較新的使用示意內容，保留待比對；未覆蓋既有定稿，也未認定為最新正式送件版。
- 數創大賞 v2 計畫書是本組已填寫的來源版本，是否為實際送件版待團隊確認。`feedback/` 保留評審回饋。
- 學校專題初評問答與本組建議放在 [System_Manual/feedback](../System_Manual/feedback/)，不混入各競賽文件。
- 其他組作品、空白競賽模板、講義與已被取代的初版保留在學校資料夾。
