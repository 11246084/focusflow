## 3. 無縫循環：整支片的設計核心

Shorts 播完會自動重播。**如果最後一格接得回第一格、最後一句接得回第一句，觀眾看不出接縫，會不知不覺多看一到兩輪。**

這件事決定了這支片所有的設計取捨。

### 三個必要條件，缺一不可

| 條件 | 做法 |
|------|------|
| **畫面** | 背景全片不換，只做「推近 → 拉遠」回到原構圖；**末格 = 首格** |
| **語句** | 尾句語意接得回首句，**全片禁用收尾詞**（以上、總結、所以結論是） |
| **音訊** | 配樂**不淡入不淡出**，首尾同音量；旁白尾端留 0.2–0.3 秒空白 |

### 這支片特有的第四個條件：嘴型

**說話的人在接點必須是閉嘴的。** 首格與末格都要是嘴巴閉合、表情中性的姿態，否則重播瞬間會看到嘴型突然跳掉。

處理方式：**旁白最後留 0.3 秒空白**，讓數位分身自然回到閉嘴的休息姿態；開頭同樣留 0.2 秒再開口。

### 因此不做的事

- **不切鏡**。全片同一個構圖，節奏靠字卡與推近拉遠做
- **不換背景**。背景一換就有「新的一段開始了」的感覺
- **不做開場的鏡頭下沉**。任何「用力」的開場動作都會讓接點被看出來

## 6. 背景：一段可無縫循環的動態

**背景全片只有一段，不切換。** 它必須自己就能無縫循環，否則整支片循環不了。

### 生成 Prompt

```
A vertical 9:16 abstract cinematic background loop.
Subject: a horizontal band of warm amber light made of countless fine glowing particles,
         flowing steadily from left to right across the lower third of the frame
Background: pure darkness, no floor, no horizon, no objects, deep black at all edges
Lighting: the particle band is the only light source; a faint warm glow spills upward
Motion: continuous steady flow, constant speed, no acceleration, no beginning, no end
Camera: locked off, completely static
Style: cinematic, low key, deep blacks, soft bloom, muted warm palette,
       the upper two thirds kept dark and empty for a person and text to sit on
Framing: vertical 9:16 aspect ratio, 1080x1920
NEGATIVE: text, letters, words, numbers, logos, watermarks, any readable content,
          light forming letters or shapes, morse code pattern,
          camera movement, zoom, pan, fade in, fade out,
          human face, recognizable person
```

### 三個關鍵設定

**`Camera: locked off, completely static`** — 背景自己不可以有運鏡。推近拉遠是後製對整個合成畫面做的，背景本身動了就對不回去。

**`the upper two thirds kept dark and empty`** — 上面三分之二要留給老師與字卡。粒子跑到臉上會很亂。

**`no beginning, no end`** — 明確要求它是持續狀態，不要有起手式或收尾。

### 做成 30 秒循環

生成的通常是 8 秒。用**首尾交叉淡化**接成 30 秒：

```bash
ffmpeg -i bg_8s.mp4 -filter_complex \
"[0:v]split[a][b];[a]trim=0:7,setpts=PTS-STARTPTS[a1];\
 [b]trim=7:8,setpts=PTS-STARTPTS,format=yuva420p,fade=t=in:st=0:d=1:alpha=1[b1];\
 [a1][b1]overlay" -an bg_loop_8s.mp4 -y

ffmpeg -stream_loop 3 -i bg_loop_8s.mp4 -t 30 -c copy bg_30s.mp4 -y
```

**接完要單獨播一次確認看不出接縫**，再拿去合成。

## 7. 語音：用現有的 7.6 秒生成

**不請本人補錄。** 直接用 `voice_clean_7s.wav` 做零樣本語音複製，生成一個**跟他差不多的聲音**。

### 這段樣本實際分析過

| 項目 | 實測值 | 判讀 |
|------|--------|------|
| 長度 | 7.60 秒 | 偏短但可用 |
| 真靜音段 | 2.09–2.25s、3.69–3.95s、7.41–7.60s（−50dB 以下） | **底下沒有壓配樂**，是乾淨人聲 |
| 平均音量 | −15.2 dB | 正常 |
| 峰值 | **−0.6 dB** | 幾乎貼頂，原素材做過限幅 |

**沒有配樂這件事很關鍵**——有配樂的樣本做出來的複製音會把音樂的音色一起學進去，聽起來會有金屬感。這段可以直接用。

**峰值 −0.6dB 要注意**：原素材被壓過，可能有輕微削峰。複製出來若帶沙沙感，就是這個原因。

### 送進語音模型前的處理

```bash
# 切掉頭尾靜音，只留說話的部分
ffmpeg -i voice_clean_7s.wav -af \
"silenceremove=start_periods=1:start_threshold=-50dB:start_silence=0.05:\
stop_periods=-1:stop_threshold=-50dB:stop_silence=0.1,\
loudnorm=I=-18:TP=-3:LRA=7" \
-ar 48000 -ac 1 voice_sample_clean.wav -y
```

`loudnorm` 把峰值拉到 −3dB，**留出餘裕避免削峰被學進去**。

### 品質預期：像，但不是本人

7.6 秒的樣本能做出**音色接近、語速語調接近**的聲音，**但不會是百分之百一樣**。熟悉他的人可能聽得出差異。

**這是可以接受的**——這支片的目標是「聽起來像老師在講」，不是騙過聲紋辨識。而且畫面已經標了 `AI 合成影像・經本人授權`，本來就沒有要冒充。

### 選型條件

| 條件 | 為什麼 |
|------|--------|
| **支援零樣本／即時複製**（instant clone） | 樣本只有 7.6 秒，需要少量樣本就能建模的服務 |
| **中文複製品質好** | 很多服務的複製主要針對英文調校，中文會走音。**用中文試聽再決定** |
| 有呼吸與換氣建模 | 這是機器感最大的來源 |
| 支援 SSML 的 `break` 與 `emphasis` | 沒有就做不出停頓長短與重音差異 |

### 如果複製結果不穩

7.6 秒偏短，有可能做出來忽高忽低或有電音感。**這時不要硬調，改走第二條路**：

從服務的內建語音庫裡挑一個**條件相近**的——成年男聲、中文、音高與語速接近——再用參數微調到接近。這樣得到的是「風格相近的聲音」而不是複製音，穩定度高很多。

**判準**：把兩版都做出來，找認識他的人聽，**選比較像的那一版**。

### 輸出規格

| 項目 | 值 |
|------|-----|
| 取樣 | 48kHz 單聲道 wav |
| 正規化 | 旁白軌 −16 LUFS |
| 後製 | HPF 80Hz；de-esser 輕壓齒音；**不要加降噪**，合成語音本來就沒噪音，加了會有水下感 |

### 循環片特有的三個要求

**尾句語調維持水平。** 下沉是「結束」的訊號、上揚是「提問」的訊號，**兩種都會暴露這是尾巴**。合成後專門聽這一句。

**首句不要強調。** 它同時是尾句的續句，唸得比尾句用力就會出現落差。

**旁白總長要短於 30 秒**，尾端留 0.3 秒空白。沒有空白的話，第二輪的第一個字會壓在第一輪的尾音上。

### 兩個要實聽的地方

`token` 全片出現 3 次（第 1、2、3 點），**唸法必須完全一致**——同一個字在接點前後聽起來不一樣，接縫立刻暴露。

`ChatGPT` 唸對沒有。

## 10. 合成

### ① 把老師合成到背景上

```bash
ffmpeg -i bg_30s.mp4 -i avatar_vertical.mov -filter_complex \
"[0:v][1:v]overlay=0:0:format=auto" -c:v libx264 -crf 18 -an composite.mp4 -y
```

若平台只給綠幕（不是透明通道），先去背：

```bash
ffmpeg -i bg_30s.mp4 -i avatar_green.mp4 -filter_complex \
"[1:v]chromakey=0x00FF00:0.18:0.05[fg];[0:v][fg]overlay=0:0" \
-c:v libx264 -crf 18 -an composite.mp4 -y
```

`0.18` 是相似度容忍值，邊緣有綠邊就往上加、人物被吃掉就往下調。

### ② 推近拉遠（0–16s 推近到 108%，16–30s 拉回 100%）

```bash
ffmpeg -i composite.mp4 -vf \
"scale=-2:'if(lt(t,16), 1920*(1+0.08*t/16), 1920*(1.08-0.08*(t-16)/14))':eval=frame,\
crop=1080:1920" -c:v libx264 -crf 18 -an zoomed.mp4 -y
```

**末格必須回到 100%**，這是畫面能接回去的關鍵。

### ③ 疊旁白與配樂

```bash
ffmpeg -i zoomed.mp4 -i narration.wav -i bgm.wav -filter_complex \
"[1:a]volume=1.0[v];[2:a]volume=0.12[m];[v][m]amix=inputs=2:duration=first[a]" \
-map 0:v -map "[a]" -c:v libx264 -crf 20 -c:a aac with_audio.mp4 -y
```

### ④ 燒字幕

```bash
ffmpeg -i with_audio.mp4 -vf "ass=script.ass" -c:a copy subtitled.mp4
```

### ⑤ 疊揭露標示（**必做，全片常駐**）

```bash
ffmpeg -i subtitled.mp4 -vf \
"drawtext=fontfile=NotoSansTC-Regular.otf:text='AI 合成影像・經本人授權':\
x=w-tw-28:y=28:fontsize=30:fontcolor=white@0.78:\
box=1:boxcolor=black@0.35:boxborderw=10" \
-c:a copy final.mp4
```

### ⑥ 循環測試（**做完必跑**）

```bash
ffmpeg -stream_loop 2 -i final.mp4 -c copy loop_test.mp4
```

輸出：`1080×1920 / H.264 / CRF 20 / 30fps / AAC 128k / faststart`
