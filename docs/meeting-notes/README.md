# 會議紀錄 Markdown 整理

本資料夾收錄可直接使用的會議紀錄 Markdown 檔案。

會議依類型分到兩個資料夾，各自使用獨立的流水序號：

- [教授會議/](./教授會議/)：`NN_YYYY-MM-DD_教授會議_簡短主題.md`
- [組內會議/](./組內會議/)：`NN_YYYY-MM-DD_組內會議_簡短主題.md`

組內會議的流水序號、日期與標題以 Notion「專題會議紀錄」資料庫為準；每份檔案的「備註」均保留 Notion 原始標題與來源連結。

模板：
[00_2026-XX-XX_會議類型_簡短主題.md](./00_2026-XX-XX_會議類型_簡短主題.md)
