## 2. 全域設定

- **影片主題**：大語言模型（LLM）是什麼
- **核心事件**：大家以為大語言模型＝ChatGPT，但其實 ChatGPT 只是其中一種
- **核心觀點**：「大語言模型」是一整類技術的統稱，「大」有具體定義（參數量、資料量、運算資源都大），不是隨便形容詞
- **觀眾原本可能以為**：大語言模型就是 ChatGPT 的別稱
- **觀眾看完後應該發現**：Google 有 Gemini、還有 Claude，這些都是大語言模型；而且「大」這個字背後是有代價的（成本極高）
- **目標受眾**：用過 ChatGPT、但沒細想過背後技術分類的人
- **影片長度**：30 秒
- **影片語氣**：知識解說

---

## 3. 寫作順序：動筆前的 4 題

1. 我要讓觀眾「想知道什麼」？→ 大語言模型到底是什麼、還有哪些
2. 我要故意延後哪個答案？→ 除了 ChatGPT 還有哪些 LLM（留到鏡06才揭曉）
3. 中途最大的反轉是什麼？→ ChatGPT 不是唯一的大語言模型
4. 最後觀眾應該記住哪一句話？→「大語言模型不是一個產品名，是一整類技術」

## 4. 視覺概念：光網路（節點擴張）

延續 V3 的「上 2/3 B-roll＋下 1/3 教師數位分身」分層，但 B-roll 換成**新的視覺隱喻**，對應「規模」這個核心概念：

```
S1  一小片稀疏的光點網路，節點間有連線   =  一般語言模型
     ↓
S2  節點與連線急遽增生，佈滿大半畫面     =  「大」＝參數量/資料量/運算量都暴增
     ↓
S3  網路分裂成幾個獨立發光的節點群       =  不只一種模型：ChatGPT、Gemini、Claude 各自獨立
```

**為什麼用節點網路而不是延續 V3 的光帶**：光帶（連續→斷開）表達的是「拆解」，這支片要表達的是「規模膨脹」與「分裂出多個獨立個體」，節點網路的疏密變化與分裂視覺上更貼切核心觀點，也讓兩支片視覺上有區隔、不會讓觀眾覺得是同一支片重貼標籤。

**要防的事**（同 V3 的光帶）：節點連線容易被生成模型誤畫成文字或圖表座標軸，negative prompt 要排除。
