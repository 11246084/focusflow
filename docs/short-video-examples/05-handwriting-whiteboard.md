# 05・手寫白板動畫（只露手）

> 共用素材、分鏡表格式、吸引力規格、聲音規格、三道驗證關見 [_shared-conventions.md](_shared-conventions.md)（v7）。本檔只寫這支片的差異。
>
> **零生成鏡、資訊密度最高。** 對 Token 這個題目，這支能把一句話寫出來、當著學生的面切開、圈出句點。
>
> **v6 變更**：v5 時代這支的地位是「十支裡唯一能演示 tokenization 的」——因為當時禁止生成畫面帶資訊。**v6 開放之後這個獨佔性沒有了**，01、04、07、09、10 都能用 profile A 把文字放進畫面。這支現在的優勢改成三點：零生成成本、逐筆浮現的過程感、以及**不需要 G2**（實拍與程式化渲染的文字不會寫錯）。

> ⚠️ **手寫內容不用生成模型。**
>
> v6 允許生成帶文字的畫面，但這支片仍然堅持實拍或程式化渲染，理由是**筆跡是逐筆浮現的過程**——生成模型給的是一張已經寫好的靜圖，做不到「跟著筆走」。這是表現力的選擇，不是紅線。
>
> 兩種合法做法：實拍手寫，或用 Remotion／After Effects 做 `stroke-dasharray` 筆跡動畫（字元由程式指定）。**兩種都不需要跑 G2**——字是人或程式決定的，不可能寫錯。

## 示範用的句子

```
今天天氣很好。
```

選這句的三個理由：**字數少（7 個字元含句點）**、**中文沒有空格所以斷詞不直觀**（正好對上老師原片講的中文斷詞很麻煩）、**結尾有句點**可以圈出來當鉤子。

> 實際切法依老師課程使用的斷詞工具而定。本檔示範用最保守的切法：`今天 / 天氣 / 很 / 好 / 。`＝ **5 個 token**。若老師課堂上用的是別的切法，**以老師的為準**——這個數字會出現在字卡上，不能自己決定。

## 拍攝配置

```
        [ 攝影機 正俯拍，距桌面 55cm，35mm ]
                    │
              ┌─────┴─────┐
              │  白紙 A3  │  ← 直式擺放，對齊 9:16
              └───────────┘
        ╱                       ╲
  [主光 左前 45°]          [補光 右前 20°]
     柔光箱                    小柔光板
```

**兩側都要有光**：單邊光會讓手投下大片陰影蓋住剛寫的字。左右都補，陰影就淡到不礙事。

### 三個手部要點

- 指甲修短、袖子捲到手肘以上
- **切完立刻把手移出畫面**，讓學生看得到剛切的位置，這是最常被忽略的一點
- 筆速放慢到 0.8 倍，直式畫面裡手快會糊

### 紙筆選擇

白紙 + 粗黑簽字筆（1.0mm 以上）。細筆在手機上等於沒寫。**不要用白板 + 白板筆**，反光會蓋掉筆跡。

**句子要事先寫好**，不要在鏡頭前現寫——30 秒不夠寫七個字再切開。開場那條底線才是現畫的。

### 替代做法：程式化筆跡動畫

用 Remotion 的 `stroke-dasharray` 動畫做筆跡逐字浮現，**字元內容由程式指定**，同樣安全，而且改切法不用重拍。這支片改切法的機率很高（要對齊老師課堂用的斷詞工具），程式化版本在這裡特別划算。

## 聲音設計（筆聲是這支片的節奏）

| 項目 | 規格 |
|------|------|
| 收音配置 | **兩支麥**：領夾麥收旁白、桌面麥收筆聲。只靠領夾麥收不到紙面的沙沙聲 |
| 筆聲音量 | 原音 +3dB，是本片除旁白外唯一的聲音層 |
| 對位 | **旁白必須跟著筆走**。講「一刀一刀切開」時四道斜線剛好畫完；講「五個」時最後一個數字剛好寫完 |
| 停頓 | 畫線時旁白可以停——學生的眼睛在追筆，耳朵不需要同時被填滿。**這支片的留白比其他支多** |
| `token` 唸法 | 真人唸即可，不用刻意標準化 |
| 配樂 | −32 LUFS 再壓 3dB，只是墊底，不可蓋過筆聲 |
| 禁止 | 不要加「書寫音效包」。真實筆觸與合成筆聲的差別聽得出來 |

## POST

這支片的畫面本身就是資訊，**額外字卡要少**，只補口播提到但紙上沒有的（例如 `= 5 個 token`）。

逐字字幕全程保留。**字幕不可蓋到紙面書寫區**，所以本片字幕距底部拉到 260px。

無生成畫面，**不需要「AI 示意畫面」標示**。

**驗收（共用清單外加）**
- [ ] 每一列的「來源」欄都有值，且 chunkId 存在於 `video_segments_text`
- [ ] 最後 5 秒是收束重述，沒有導流字卡
- [ ] **切法與老師課堂使用的斷詞工具一致**，字卡上的 `5` 不是自己決定的
- [ ] 手寫內容為實拍或程式化渲染，未經生成模型
- [ ] 每次畫完手都移出畫面
- [ ] 手機實機看過，最細的筆畫讀得到
- [ ] 字幕沒有蓋到書寫區
- [ ] G3：ASR 回讀與腳本相似度 ≥ 0.95，`token`／`句點`／`五個` 全中

**這支片只需要跑 G1 與 G3。** 沒有任何生成畫面，G2 完全不適用——這是它在 v6 架構下最大的成本優勢：省掉整條出圖／回讀／重試的迴圈。

`五個` 這個關鍵詞要特別檢查：它是畫面上數出來的數字，**講錯會直接跟畫面打架**。
