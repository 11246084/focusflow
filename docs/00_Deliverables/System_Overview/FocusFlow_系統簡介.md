## 前言

長篇教學影片不易快速定位知識點，學生複習時常需反覆拖曳時間軸。FocusFlow AI 結合語音辨識、語意檢索、生成式問答與時間戳，讓學生以自然語言查詢教材，並回到原始影片確認內容。

## 系統功能簡介

- 課程與影片管理：教師建立課程、上傳影片並查看處理狀態。
- 教材知識化：AI Pipeline 擷取音訊、產生逐字稿、切分片段並建立向量資料。
- 課程智慧問答：學生針對可存取課程提問，取得回答與引用片段。
- 時間戳回溯：由引用片段跳轉影片時間位置，查看完整講解。
- LINE Bot：綁定帳號後選擇課程，透過 LINE 查詢教材。

## 系統使用對象

大專院校學生可用於預習、複習與重點查找；教師與教學協助人員可用於教材管理及學習支援。系統帳號分為學生、教師與管理員，助教的實際權限由團隊另行確認。

## 系統特色

回答連結到課程來源與影片時間點，方便學生查證；Web 與 LINE 提供不同使用入口。系統透過角色及修課資格限制課程內容存取，並以教材內容支援問答。AI 仍可能答錯，使用者應以原始教材及教師說明為準。

## 系統開發工具

前端使用 React、Vite、JavaScript、HTML 與 CSS；後端使用 Node.js、Express、Mongoose 與 JWT；資料儲存使用 MongoDB。影片處理使用 Python、Faster-Whisper、FFmpeg 與 Gemini Embedding，並整合 LINE Messaging API 及 YouTube。開發文件列有 Visual Studio Code、GitHub、MongoDB Compass 與 Swagger UI。

## 系統使用環境

使用者需具備可連網的電腦或行動裝置、支援影片播放的瀏覽器；LINE 問答另需 LINE App。伺服器需提供 Node.js 後端、Python 影片處理環境、MongoDB 與已設定的外部服務。最低裝置規格、瀏覽器版本及網路條件仍待相容性測試確認。

## 結論及未來發展

FocusFlow 將影片整理成可檢索、可提問、可回溯的教材，目標是協助學生查找知識並減輕重複問答負擔。效益仍需實際使用研究支持。後續將持續驗證檢索與回答品質、完善短影片產製與審核流程，並評估學習分析及其他平台整合。
