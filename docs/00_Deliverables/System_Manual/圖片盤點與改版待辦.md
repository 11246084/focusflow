# 圖片盤點與改版待辦

本文件記錄 2026-10-18 的章節圖檔整理、保留項目與尚待確認來源的圖。現行圖號與名稱取自章節圖說，請先查下方對照表，再從同一資料夾開啟成品或原始碼。舊版清理由 Git 歷史追溯，不據此宣稱圖面內容已重繪或通過人工驗收。

## 命名與保留規則

- 現行圖檔與原始碼共置於 `figures/ch01/`～`figures/ch15/`，主檔名相同；附錄檔名沿用 `圖15-x-x`。
- 有原始碼的圖與截圖使用章節圖說的圖號、名稱，不加 `-vX-X`；同一現行版本的 PNG／SVG 可一併保留。
- 第 3 類圖保留原檔名、全部版本與內容，待使用者確認來源。
- 未被章節引用的舊圖源與截圖已清除；Python／JavaScript 舊腳本仍保留，避免刪除任何腳本。
- 共用樣式與工具放在 `figures/_shared/`；`tools/` 的既有產圖命令保留轉接入口。
