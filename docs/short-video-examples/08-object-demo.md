# 08・實物演示一鏡到底

> 共用素材、分鏡表格式、吸引力規格、聲音規格、三道驗證關見 [_shared-conventions.md](_shared-conventions.md)（v7）。本檔只寫這支片的差異。
>
> **v6 變更**：無實質變動。這支全部實拍，沒有生成鏡，**不需要 G2**——紙條上的字是印出來的，不可能寫錯。與 05 一樣是 v6 架構下驗證負擔最低的類型。
>
> 用桌上的實體物件把抽象概念做出來，**一鏡到底不剪接**。不剪接的連續性讓學生相信這是真的發生了，不是後製拼的。
>
> Token 這個題目的實物版很直接：**一張寫著句子的紙條，當著鏡頭剪開。**

> **一鏡到底沒有補救機會。** 演砸就重來，所以拍之前先空手排練三次。實際拍攝通常要 5–10 次才有一次乾淨的。
>
> **紙條上的字是印出來的**，內容由人決定，不需要 G2 驗證。這支片與 05 是十支裡唯二完全不碰生成畫面的。

## 道具與切法

紙條上寫：`今天天氣很好。`

切法示範用最保守的：`今天 / 天氣 / 很 / 好 / 。` ＝ **5 個 token**。

> **切法要跟老師課堂用的斷詞工具一致**，這個數字會出現在字卡與旁白裡，不能自己決定。若老師用的工具切法不同，改紙條上的切點與旁白的數字。

## 分鏡腳本表

一鏡到底不切鏡，**鏡號全部是 S1**，變的是手部動作與字卡。

| 鏡號 | 秒數 | Beat | 畫面 | 聲音 |
|------|------|------|------|------|
| S1 | 0–3s | **鉤子・清單預告** | 景別：正俯拍（或 30° 斜俯）・35mm・距桌面 70cm<br>運鏡：固定<br>構圖：長紙條橫置畫面中央，字清楚可讀，上下留白<br>光影：主光左後 120° 逆光柔光箱 + 右前反光板<br>動作：**剪刀在 1 秒內「喀、喀、喀」三聲空剪入畫**（本片的 pattern interrupt——動作＋聲音同時到）<br>字卡：`幾個 token？` 96px，0.3s 彈入 | 旁白：「這句話丟進 ChatGPT／會被拆成**幾個**東西？」<br>語氣：句尾上揚提問，重音落在「幾個」。旁白起在第 1.2 秒，前 1 秒只有剪刀聲<br>字幕：逐字同步<br>配樂：**無**或 −34 LUFS（剪刀聲就是節奏）<br>音效：**三聲空剪，原音 +3dB，是全片的鉤子本體**<br>收音：桌面收音麥／HPF 80Hz／安全軌 −12dB<br>來源：`chunk_0005`・`rewritten` |

總字數 168。**無 `ai_added` 句。**

**備選開場**：預設「清單預告」。「錯誤警告」版可改成開場先剪一刀在字的正中間（示範錯的切法）再搖頭把它拿掉；「反常識」版留白 1 秒再讓剪刀突然入畫。三種都不要動到一鏡到底的原則。

## 拍攝配置

```
        [ 攝影機 正俯拍或 30° 斜俯，距桌面 70cm，35mm ]
                        │
              ┌─────────┴─────────┐
              │  今天天氣很好。    │  ← 長紙條橫置，
              └───────────────────┘     佔畫面中央三分之一
        ╱                             ╲
  [主光 左後 120° 逆光]          [反光板 右前]
     柔光箱                          白色
```

**用逆光**：主光從紙條後方 120° 打，紙的邊緣會出現一圈亮線，剪開後的斷面也看得出來。順光拍白紙等於拍一片死白。

### 四個要點

- 剪要**剪到聽得到聲音**——剪紙聲是這支片的節奏來源，收音要收得到
- 每次剪完**手立刻移出畫面**，讓學生看得到剛剪的位置
- **紙條上的字要夠大**（至少 60pt 印出來），直式畫面裡小字等於沒寫
- 桌墊用亞光深色，不要用玻璃或白桌（反光會照出燈具與拍攝者，白桌則讓白紙糊掉）

### 道具注意

- 紙條**印出來，不要手寫**——手寫在一鏡到底裡容易歪，而且重拍時每張都不一樣
- 多印 10 張備用。這支片會重拍 5–10 次
- 剪刀選**啞光金屬或深色**，亮面剪刀在逆光下會反光炸掉

## 聲音設計（十支裡聲音最重要的一支）

一鏡到底不能切鏡，所以**節奏完全由聲音決定**。

| 項目 | 規格 |
|------|------|
| 收音配置 | 桌面麥收剪紙聲 + 領夾麥收旁白，**分兩軌**。混在一軌就沒辦法分別調整 |
| 開場三聲 | 「喀、喀、喀」間隔各 0.3 秒，**是全片最重要的 0.9 秒**。收不到就等於這支片沒有鉤子 |
| 剪紙聲 | 四刀每一刀都要聽得到，節奏均勻。手要慢到每刀分得開 |
| 旁白對位 | 旁白**永遠落在動作之後 0.2 秒**，先看到再聽到。反過來會變成預告，失去演示感 |
| 留白 | 剪的時候旁白可以完全停。這支片的靜默是設計，不是漏詞 |
| `token` 唸法 | 真人唸即可，不用刻意標準化 |
| 配樂 | 無或 −34 LUFS |
| 環境 | 拍攝現場**必須關冷氣**。桌面麥距離近、增益高，冷氣聲會整支蓋掉剪紙聲 |
| 禁止 | 不要用音效包替換剪紙聲。合成音與真實剪紙的差別很明顯，而且會失去「這是真的在發生」的感覺 |

## POST

字卡**跟著紙片的位置放**，不要全部堆在上方——這樣學生的視線不用來回跳。一鏡到底的畫面已有連續性，字卡多了會打斷「這是連續發生的」這個感受。

無生成畫面，**不需要「AI 示意畫面」標示**。

**驗收（共用清單外加）**
- [ ] 每一列的「來源」欄都有值，且 chunkId 存在於 `video_segments_text`
- [ ] 最後 5 秒是收束重述，沒有導流字卡
- [ ] **切法與老師課堂使用的斷詞工具一致**，旁白裡的「五個」不是自己決定的
- [ ] 真的是一鏡到底，沒有隱藏剪接點
- [ ] 紙條上的字在手機上讀得到
- [ ] 每次剪完手都移出畫面
- [ ] 桌面沒有反射出燈具或拍攝者
- [ ] 收得到剪紙聲，開場三聲清楚
- [ ] G3：ASR 回讀與腳本相似度 ≥ 0.95，`token`／`ChatGPT`／`句點`／`五個` 全中

**只需要跑 G1 與 G3。** 沒有生成畫面，省掉整條出圖／回讀／重試迴圈——這是這支片在 v6 架構下的成本優勢。

`五個` 要特別檢查：**它是畫面上真的剪出來的段數**，講錯會直接跟畫面打架。
