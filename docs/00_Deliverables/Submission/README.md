# 繳交清單

四技第115413組「FocusFlow AI」的學校繳交項目、期限與目前狀態。規定以系辦公告為準，本頁只做追蹤；公告更新時先改這裡。

規定來源（原檔在 [System_Manual/source-documents](../System_Manual/source-documents/)）：

| 簡稱 | 檔案 | 內容 |
|---|---|---|
| 時程 | `115-1_專題時程規劃.docx` | 複評、觀摩展、校外競賽、最終文件的日期 |
| 繳件 | `115-1_專題資料繳件注意事項.docx` | 複評文件、觀摩展資料、最終版的繳交項目 |
| 觀摩展 | `115-1_校內觀摩展繳件暨參展注意事項.docx` | 海報規格、觀摩展檔名、參展規定 |
| 最終文件 | `115-1_專題最終文件說明.docx` | 膠裝、文件順序、授權書、書背、FTP 上傳 |
| 書背 | `115-1_專題書背.doc` | 書背範例 |
| 手冊範本 | `115年_系統手冊.doc` 附件 5 附註 | FTP 上傳的另一份清單（VPP、MDF／LDF、安裝程式） |

存放原則：

- 定稿 PDF（系統手冊、系統簡介、簡報）以規定檔名 commit 進 repo，只放定稿，不放中間版。
- 影片、海報圖檔、資料庫交付包、安裝程式等大檔不進 repo，放個人帳號雲端硬碟的 `學校專題/繳交/`（學校帳號空間不足），本頁記錄位置。
- 助教 Email 與 FTP 位址見系辦公告，不寫進公開 repo。

- 成果影片：「繳件」說明欄寫「系統簡介影片」、範例寫「-觀摩影片」；「觀摩展」寫「系統成果影片」、範例寫「-成果影片」。
- 簡報：「繳件」說明欄寫「-系統簡介」、範例寫「-簡報」；「最終文件」寫「-簡報」。
