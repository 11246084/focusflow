# 教授會議（各組進度報告與競賽組別討論）

- 會議日期: 2026-07-28
- 會議時間: 10:58 起
- 會議類型: 教授會議（進度回報）
- 與會者: 邱偉豪、張庭語、鍾百陶、張家瑜、蒯思齊（教授）

## 討論內容

1. 雲端部署與 YouTube 影片管理

- 背景：FocusFlow 已能由手機及外網透過 IP 存取，但 DNS 與 YouTube 自動上傳仍有問題。
- 內容：
  - 伺服器已使用 Nginx 串接前後端，`focusflow.ntub.edu.tw` 已申請但尚未連通。
  - YouTube OAuth 已申請，但自動上傳仍處理失敗，需繼續確認平行處理、配額或憑證流程。
  - 系統刪除影片後，不宜直接永久刪除 YouTube 教材；教授建議研究未公開影片與分享清單權限，移除課程時撤銷觀看權限。
- 結論傾向：先驗證 YouTube 權限管理是否可由 API 自動化，再決定刪除語意與實作方式。

2. 前端介面與權限入口

- 背景：前端已完成通知欄、個人頁、頭像、手機版與品牌視覺調整。
- 內容：
  - 手機版側邊導覽由直排改為橫排，Logo 與配色已統一。
  - 管理員入口已可阻擋一般使用者，待確認後從一般介面移除，改由指定網址進入。
  - 尚需修正手機版課程頁重複標題及測試中發現的問題。
- 結論傾向：完成剩餘介面修正後移除一般管理員入口，保留權限驗證。

3. AI 影片處理、圖片 Embedding 與多輪問答

- 背景：Pipeline 已能同時上傳兩部影片並完成處理，回答品質也較前一版提升。
- 內容：
  - 圖片 Embedding 尚未開始，切分策略需針對教學影片設計，例如投影片換頁、同一張投影片持續講解等情境。
  - 教授認為切分規則應由學生依自身學習痛點發想，這是專題價值的一部分。
  - 團隊提出多輪問答需求；教授建議逐版完成，這一版先不實作，下次再提出討論。
- 結論傾向：優先研究教學影片專用的圖片切分策略，多輪問答延後。

4. 後端、FAQ 快取與使用者功能

- 背景：後端持續改善回答品質、快取、通知、註冊登入與頭貼功能。
- 內容：
  - 檢索候選數由 3 筆提高至 15 筆，並加入課程外問題的拒答提示。
  - 完全相同或語意相近的問題可命中 FAQ 快取；影片新增、刪除或重新處理時需清除舊快取。
  - 已建立影片完成通知、管理員維護通知與已讀／未讀狀態。
  - 頭貼可由後端保存；部分頁面仍有硬編碼姓名，需要逐步排查。
- 結論傾向：繼續修正測試與顯示問題，並以實際命中率與回答品質驗證快取效果。

5. 成本估算與損益平衡

- 背景：團隊估算 Azure、Gemini 問答與 Embedding 成本，並以替代助教工時評估效益。
- 內容：
  - Azure 情境估算約每月新臺幣 5,500 元，實際規格能否穩定承載仍需部署驗證。
  - 問答成本以 50 人、每人每週 20 題、18 週為假設；Embedding 成本尚待實測。
  - 教授建議效益分析除人工成本外，加入「隨處學習」與「助教不足」兩項難以完全以金額呈現的價值。
  - 可用偏鄉醫療類比資源不足：問題不只在價格，而是即使有預算也不一定有人力可提供即時協助。
- 結論傾向：成本報告保留假設與待實測項目，效益則同時呈現可量化節省與教育資源不足問題。

6. 競賽組別與文件準備

- 背景：團隊比較 NIICC 與 InnoServe 教育 AI 組，並確認近期繳件時程。
- 內容：
  - NIICC 已完成報名，7/29 參加臺北訓練營，8/7 前繳交企劃書與需求書。
  - 教授建議選擇教育 AI 專門組，而非評審偏好影響較大的 IP 組。
  - 評分重點包含可行性、穩定性、實用性、可執行度與整合性，企劃書需補上雲端成本及其他佐證資料。
- 結論傾向：以教育 AI 組為參賽方向，依評分項目補強企劃書及需求書。

7. 短影片生成

- 背景：Shorts 顯示與修課過濾已有進度，但生成方式尚未定案。
- 內容：
  - 本週先蒐集短影片剪輯與生成工具的資料，不直接進入實作。
  - 需評估畫質、伺服器安裝需求、成本及是否適合教學影片。
- 結論傾向：下週依調研結果再決定短影片生成方案。

## 決議事項

1. YouTube 影片刪除優先研究未公開影片與分享權限管理，移除課程時撤銷觀看權限；先確認 API 是否可自動化。
2. 圖片 Embedding 依教學影片特性設計切分策略，由團隊提出具體方案。
3. 損益平衡分析加入「隨處學習」與「助教不足」的效益佐證，並清楚標示尚待實測的成本。
4. 競賽選擇教育 AI 專門組；7/29 參加訓練營，8/7 前完成企劃書與需求書。
5. 短影片生成本週只做方案調研，下週再決定是否及如何實作。
6. 多輪問答本版暫緩，下次再提出討論。
