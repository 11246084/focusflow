# 教授會議（第一階簡報練習）

- 會議日期: 2026-06-09
- 會議類型: 教授會議（成果檢視）
- 與會者: 邱偉豪、張庭語、鍾百陶、張家瑜、蒯思齊(教授)

## 討論內容

1. 簡報流暢度與時間控制

- 背景：第一階段簡報前進行完整排練，需要確認內容節奏與時間分配。
- 內容：
  - 老師建議開頭介紹要更有力，並提醒總時間控制在 15 分鐘內。
  - 目前排練時間約 12-14 分鐘，仍需確保每位成員時間穩定。
  - 每位成員口說時間約控制在 2.5 分鐘以內。
- 結論傾向：各成員需微調講稿並再進行一次完整計時排練。

2. 競品比較與技術細節取捨

- 背景：目前簡報部分內容講得過細，可能壓縮核心價值說明時間。
- 內容：
  - 與 NotebookLM、TronClass 等競品比較的部分講太久。
  - 競品比較只需用一兩句話點出最大差異即可。
  - 操作畫面細節不需逐一唸出，直接帶過。
  - Whisper 設定等技術細節投影片有帶到即可，不需口頭展開。
- 結論傾向：刪減口頭技術細節，簡報口說重心放在問題、解法、展示效果與價值。

3. Demo 展示與設備準備

- 背景：現場展示需確保系統與簡報切換順暢。
- 內容：
  - 需思考影片展示效果，讓 Demo 能突顯 AI 回答與片段定位的即時性。
  - 討論是否使用 iPad 或 Surface 進行現場 Demo。
  - 需測試轉接頭、網路、平板瀏覽器電腦模式與前端介面呈現效果。
  - 建議準備兩台電腦，一台播放投影片，一台預先開好系統待命。
- 結論傾向：正式展示前需完成設備測試，並準備備援展示設備。

4. 商業邏輯與教師端管理後台

- 背景：專題簡報需加強規模化潛力與教師端價值。
- 內容：
  - 老師建議加強描述專案的規模化潛力。
  - 技術細節討論延伸到教師端管理後台，例如如何監控學生學習行為。
- 結論傾向：簡報需補強商業擴張邏輯與教師端管理功能的應用價值。

5. 現場動線與形象準備

- 背景：正式報告需確認上台順序、站位與整體專業形象。
- 內容：
  - 團隊確認穿著以西裝或正裝為主。
  - 需確認上台站位順序，張嘉瑜靠近講桌，其他人靠走道。
- 結論傾向：報告當天依既定站位與正裝呈現，降低現場混亂。

## 決議事項

1. 各成員需修改講稿，確保每人控制在 2.5 分鐘以內。
2. 競品比較只保留最大差異，不逐頁細講操作畫面。
3. 技術細節不口頭展開，投影片有帶到即可。
4. 正式展示準備兩台電腦，一台播投影片，一台開好系統待命。
5. 需測試平板以瀏覽器電腦模式呈現前端介面。
6. 報告當天採正裝，並先確認上台站位順序。
