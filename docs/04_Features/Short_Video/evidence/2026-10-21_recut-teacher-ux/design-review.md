# recut 教師審閱頁設計方案與自評

2026-10-23 第六輪。第五輪已依現有教師介面校準，本輪依六則瀏覽器回饋精簡常駐資訊；下方保留前輪方案與自評作修訂依據。這是設計原型，不是正式前端功能或教師驗收；產品規則以[體驗決策](../../decisions.md)與[產製決策](../../recut-design-decisions.md)為準。

## 本輪定案（2026-10-23）

使用者在第六輪修訂後回覆「OK，目前先這樣定案了」。以本版七個狀態與精簡資訊設計作為本輪實作、評估基準；Q3、Q4、Q12、Q13 已依[體驗決策 UX-19](../../decisions.md#本輪已定案明細2026-10-23)收束。以下各輪自評保留當時的待確認描述，作為歷史取捨；真實影音、背景任務與代理操作測試仍須後續執行，未因設計定案而完成。

## 第六輪：減少常駐說明，集中審閱資訊

依 UX-18、frontend-design 的既有風格優先與 design-critique 的視覺層級原則調整。先移除重複，再以少量有文字的圖示整理必要資訊；不新增另一套主題、額外審核階段或常駐教學框。

| 瀏覽器回饋 | 修改與取捨 |
|---|---|
| 1：題目下課程／原音小字干擾 | 課程與講次收進「課程來源」，有需要再展開；原音資訊集中於右側 |
| 2：頂欄副標干擾 | 移除功能宣傳式副標，保留頁面名稱與必要操作 |
| 3：日期／版本／自評頁尾干擾 | 移除產品工作區內的頁尾，資訊收進上方「原型工具」；原型識別仍置於產品區外 |
| 4：右側說明改視覺化 | 用耳機搭配「老師原音」標記、時鐘搭配預估秒數；移除敘述與重複的待確認狀態，不使用沒有標籤的圖示 |
| 5：製作後提醒干擾 | 移除例行提醒，流程列與「通過講稿，製作短片」已說明去向；必要錯誤／停用提示仍保留 |
| 6：稿尾與右側重複 | 移除稿尾原音／時長列，完整講稿到正文即結束 |

自評：稿件與兩個決定按鈕更集中，必要的原音身分與預估時長仍在同一處。課程來源是次要查詢，使用可鍵盤操作的展開入口，支援 Escape／點外部收起；沒有將原音標記做成虛假的播放按鈕。此為同一作者自評，未進行真人操作測試，Q3、Q12、Q13 與整組素材仍未因精簡而視為核准。

本輪實際驗證：

- 已重製七張桌機 PNG，另檢視講稿桌機與手機截圖；1480、1024、768、390px × 七場景共 28 組檢查，無水平溢出或指定文字截字。
- 四種寬度均確認課程來源可用 Enter 展開、Escape 收起並返回焦點、點外部收起；來源浮層與原型工具選單均未超出畫面，原型場景選單可正常切換。
- 講稿與 AI 建議頁的原音標記及預估時長只呈現一次；原副標、稿尾及設計頁尾節點已移除。修改後停用、停用理由與全部復原解除仍可運作；減少動態效果偏好會關閉展開圖示的轉場。
- 使用既有 Puppeteer／Chromium；本輪紀錄位於忽略追蹤的 `output/playwright/recut-information-audit.json`。瀏覽器無 JavaScript 錯誤，未發出 HTTP(S) 請求；沒有實際影音、AI、後端或發布驗證。
- 僅修改設計原型與討論文件，未改正式前端；未執行整套前後端測試、部署或教師驗收，系統手冊不因此改寫成已實作。

## 第五輪：先服從既有系統風格

frontend-design 明確要求依使用者已指定的視覺方向設計。本輪先讀[共用樣式](../../../../../frontend/focus-flow/src/index.css)、[教師短影片頁](../../../../../frontend/focus-flow/src/pages/TeacherShortScripts.jsx)、[Sidebar](../../../../../frontend/focus-flow/src/components/Sidebar.jsx)、[Topbar](../../../../../frontend/focus-flow/src/components/Topbar.jsx)與[導覽設定](../../../../../frontend/focus-flow/src/components/navigationConfig.js)，再改原型，避免用另一套視覺取代現有產品。

| 項目 | 現有程式依據與本輪處理 |
|---|---|
| 背景 | 沿用 `.ff-bg` 的深梅紫 `#381230` 與三層橘／梅紫徑向漸層，移除淺色工作區 |
| 卡片 | 沿用 `.card` 的 `#260c1e`、白色低透明邊線與 22px 圓角；講稿維持限寬與清楚段落 |
| 側欄 | 依現有 232px 浮動側欄、24px 圓角、實際品牌 SVG 與教師導覽名稱重建示意，不再畫另一套實心直角側欄 |
| 動作與字體 | 品牌橘 `#F14F21`、膠囊形主要／次要按鈕；沿用 Noto Sans TC／Microsoft JhengHei，正文保留易讀字級。主要按鈕採 19px 粗體，以符合本輪使用既有橘色時的大字對比門檻 |
| 結構 | 保留細流程列、稿件優先、上方 AI 入口、單一審閱操作區；不更動先講稿再成品的兩次核准 |

本輪仍依 design-critique 自評，但新增「與現有系統一致」為先決條件。前三輪細流程列方向保留，第四輪的白稿視覺已依 UX-17 否決；頁面重建是示意，不代表已整合正式 React 元件或實際登入驗證。

## 第四輪方案紀錄（淺色視覺已否決）

對象是要核對授課內容、可能沒有剪輯背景的教師。主要工作是先閱讀原話，再確認影片；因此畫面的主角是講稿與影片，流程列只提供位置感。

| 項目 | 選擇與理由 |
|---|---|
| 基底色 | 深色導覽 `#111827`、閱讀區底色 `#EEF2F7`、稿面 `#FFFFFF`；將閱讀內容從網站導覽分開，不用大面積彩色卡片競爭注意 |
| 文字與動作 | 內文 `#1F2C42`、次要文字 `#5E6C80`、主要動作 `#C2472D`。延續 FocusFlow 橘色辨識，按鈕加深以維持白字對比；不修改正式產品全站色票 |
| 字體 | 沿用現有產品的 Noto Sans TC／Microsoft JhengHei 字族；離線截圖以本機正黑體呈現。講稿約 19px、行高約 1.9，介面約 14～16px；數字採等寬數字排版 |
| 版面 | 左側導覽、頁首題目與細流程列、中央講稿或影片、右側當前操作。內文控制行寬並靠左；減少重複框線與相同造型的卡片 |
| 步驟 | 試作 Q13 的小節點與細線，維持 UX-16 的細長要求。修改時名稱改變，但不新增階段；製作仍是系統工作，核准仍只有講稿與成品兩次 |
| 動效 | 回應切換分頁、展開修改與進度狀態；避免整頁每個區塊分別滑入。減少動態效果偏好啟用時停用轉場 |

```text
導覽 │ 題目、課程
     │ 確認講稿 ─── 製作短片 ─── 確認成品
     │ 完整講稿／AI 建議       當前審閱操作
     │ 可閱讀的完整原話        修改、通過
```

方案檢視：初步若把時長做成大數字、各項狀態各放一張卡，仍會回到前版的資訊競爭。本版將時長降為行內資訊，保留一個清楚的稿面；強調只用在內容與主要動作。影片內 N2 圖卡色系不隨網站稿面變色。

淺色稿面及整體版面是本輪提案，尚未獲使用者核准；不把重新嘗試解讀為已選定 Q3、Q12 或 Q13。

## 第四輪自評與驗證（歷史）

以下是同一作者依 design-critique 框架進行的自評；沒有代理使用者、教師或獨立設計師參與，不稱為獨立評審。

### 第一印象與視覺層級

先看題目，再進入白色講稿；時長降為次要行內資訊，流程列高度 30px。成品頁先看直式影片，再看右側的當前操作；原音查核開啟時，在相同位置替換操作，並保留影片暫停位置。講稿靠左、正文有界定行寬，避免文字橫跨整個工作區。

### 可用性

| 發現 | 嚴重度 | 修正與檢查 |
|---|---|---|
| 初稿逐句試聽只剩播放圖示，與教師需要白話入口的要求不符 | 中 | 改成「聽老師原話」文字按鈕；手機排列到來源句下方，避免擠壓文字 |
| 影片播放按鈕初稿只有 36px | 中 | 加大為 44×44px；步驟節點是非互動狀態，不假裝可任意跳階段 |
| 從講稿進入修改時，尚未改句也被標成未套用 | 中 | 依實際選句與基準比較；未改可繼續，改句後停用，全部復原後解除 |
| 模擬成品的時長原本可能與核准講稿不一致 | 高 | 改從相同選句計算，閱讀版也從同一組原話產生；示意秒數仍不是原音測量 |
| 成品僅修字幕時不應重新通過未變的講稿 | 中 | AI 只採納字幕修正時，原型直接走重製與新成品審閱；若增加原話，先回講稿確認 |
| 原音主動停止後，成品的畫面狀態可能仍顯示播放中 | 高 | 返回成品時保持暫停，原本已暫停時試聽說明也保持一致 |

### 一致性與無障礙

- 深色導覽與品牌橘延續既有身分；淺色稿面是本輪視覺提案，尚待使用者確認。影片內維持 N2，不把稿面顏色帶入圖卡。
- 主動作、次動作與來源試聽各有固定樣式；一般按鈕／試聽控制至少 44px 高，勾選項的標籤可整列點選。
- 代表性文字色票計算：正文對白底 14.03:1，次要文字對工作區底色 4.75:1，主按鈕白字 4.96:1，綠色文字對白底 5.70:1。不是所有像素／影片字幕的完整 WCAG 稽核。
- 已確認鍵盤焦點有 3px 外框；減少動態效果開啟時停用原型內容動畫。未用螢幕閱讀器做完整測試。

### 實際驗證

| 範圍 | 結果與限制 |
|---|---|
| 七張桌機 PNG | 1440px 寬重製；沒有頁面 JavaScript 錯誤、水平溢出或指定文字區截字；有意隱藏給輔助科技的標題不當成截字 |
| 響應式 | 1440、1024、768、390px，各七個場景，共 28 組版面檢查；手機另輸出講稿與成品截圖檢視 |
| 修改與回復 | 從講稿開修改、加回原話、核准停用、套用、取消保留選句、再次套用後回講稿確認 |
| 兩階段審核 | 通過講稿→模擬製作階段→成品待確認，沒有直接發布；成品可切換完整講稿與 AI 建議 |
| AI 與查核狀態 | 部分採納建議、字幕修正的重製路徑、原音停止後回成品且維持暫停；沒有呼叫模型或播放聲音 |
| 長稿／動效／焦點 | 暫時加長講稿、捲動 1200px 後 AI 入口仍可見；減少動態效果與鍵盤焦點檢查通過 |
| 外部副作用 | 原型檢查沒有 HTTP(S) 請求；沒有啟動正式服務、修改資料庫、製片或發布 |

瀏覽器檢查用既有 Puppeteer／Chromium，結果放在忽略追蹤的 `output/playwright/recut-redesign-audit.json`；不是 Playwright CLI 或正式前端測試。原型固定 1.8 秒的場景切換是模擬等待，不是任務效能證據。

### 保留的優點與後續優先項目

1. 保留：稿面主次、AI 建議上方入口、精簡右側與小節點流程列；它們符合本輪設計目的，但易用性仍需真人驗證。
2. 優先由使用者確認整體視覺、Q12 資訊配置及 Q13 步驟方向，不把本輪重繪當成已定案。
3. Q3 真實音訊結束、播放位置恢復與雙音源互斥須在媒體接入後驗證；本機畫面狀態不能證明聲音切換順暢。
4. 真正版本保存、背景取消、失敗回復及字幕／配圖手動編輯仍待正式系統實作。本輪未修改正式前端，故不宣稱系統手冊已能描述為完成，亦未跑整套前後端測試或部署。

## 第五輪一致性自評與驗證

- **第一印象／一致性**：修正第四輪另立淺色主題的問題；背景取自現有 `.ff-bg`，卡片與側欄圓角、膠囊按鈕、品牌圖與教師導覽名稱均與原始程式核對。不是僅將白色換成任意深藍，也沒有將原公司案例的品牌套入 FocusFlow。
- **視覺層級／可用性**：保留限寬講稿、30px 細流程列、上方 AI 分頁及單一審閱操作區；本輪只校準外觀與共用框架，不增加操作步驟。
- **無障礙限制**：沿用系統 `#F14F21` 橘底，主按鈕改 19px／700 粗體，以大字對比門檻判讀；原型一般操作仍至少 44px。這不等於完整 WCAG 稽核，亦不代表正式系統的其他小字／透明背景都已驗證。
- **來源一致性檢查**：瀏覽器計算值確認底色 `rgb(56,18,48)`、卡片 `rgb(38,12,30)`、主色 `rgb(241,79,33)`、卡片 22px／側欄 24px／按鈕 50px 圓角、Topbar 高 62px；品牌 SVG 成功載入，字標 focus 為白、flow 為金色。
- **響應式與狀態**：1440、1024、768、390px 的七場景共 28 組版面檢查通過；無水平溢出或指定文字截字。再確認修改停用／全部復原解除、查核原音後保持暫停，以及減少動態效果偏好。
- **證據與範圍**：七張 PNG 已重出，另檢視手機稿面；檢查紀錄在忽略追蹤的 `output/playwright/recut-theme-alignment-audit.json`。無頁面 JavaScript 錯誤、無 HTTP(S) 請求；沒有啟動正式服務、登入、實際媒體或發布。以程式與重建原型為比對依據，未宣稱取得正式站的同畫面截圖或已完成 React 整合。

淺色提案已否決；Q3、Q12、Q13 及新版素材確認仍待使用者回覆。正式系統及系統手冊完成狀態未因原型重做而改變。
