## 4. 負向題審查規則

### N01｜跨課程負向題

- 外課課程：影像處理導論（`69f82564736febac6db8e97b`）
- 外課 videoId：`6a67ffcb95668cc2b904f3b9`
- 外課 Leaf：`chunk_0122`～`chunk_0132`
- 時間：1364.42～1465.70 秒
- 外課支持內容：替換過時資料、加入新資料並重新訓練，可讓模型從新資料中學到當時的語言規則與用法。
- 語意接近原因：題目使用 OpenCV 教材也會出現的「資料、模型、訓練、資料品質」概念，能測出檢索是否只因表面詞彙相近而跨課程取材。
- OpenCV 不支持確認：OpenCV 129 筆正式 Leaf 雖有模型、訓練與資料品質相關內容，但沒有資料時效、定期替換或語言習慣的答案。

N01 的 baseline 判定必須遵守：

1. Atlas 找到表面相關的 OpenCV Leaf，本身不算失敗。
2. 不得使用「影像處理導論」或其他外課內容回答。
3. 不得產生外課 citation。
4. 如果 OpenCV Leaf 不足以支持「資料過時、定期替換、語言習慣」的答案，正確結果是拒答。

### N02｜無答案負向題

- 預期支持來源：無
- OpenCV 不支持確認：129 筆正式 Leaf 中，`Canny`、邊緣偵測、雙閾值、高低閾值及 `threshold` 均沒有足以支持答案的內容。
- 合理性：這是合理的 OpenCV 課程問題，不是刻意使用與課程無關的題目。
- baseline 判定：必須回覆無答案，citation 必須為空；不得使用模型通用知識補答。
