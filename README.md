# focus flow

## 專案簡介
focus flow 是一個利用 AI 將長內容（例如教學影片、錄音）轉換為可消化的短影音學習單元的系統。

本專題目前第一階段的目標，是先建立一套基礎問答系統，讓使用者能根據問題查詢對應的教學影片內容，並取得相關回答與影片片段資訊。

---

## 專案目標
本專題預計分為四個階段：

1. **第一階段：文字版問答系統**
   - 使用者可透過介面或 Line Bot 提問
   - 系統根據教學影片內容回答問題
   - 提供對應影片片段或時間戳資訊

2. **第二階段：短影音生成**
   - 根據教學內容自動切分重點
   - 產出較短的學習單元

3. **第三階段：網頁化版本**
   - 建立完整前端介面
   - 提供更完整的課程與影片瀏覽體驗

4. **第四階段：個人化課程版本**
   - 根據使用者需求與學習行為
   - 推薦個人化學習內容

---

## 核心功能
目前第一階段 MVP 預計包含以下功能：

- 使用者登入與權限管理
- 教師上傳課程影片
- 系統處理影片內容（語音轉文字、切段、建立檢索資料）
- 使用者提問與問答回覆
- 回傳對應影片片段或時間戳
- 後續支援 Line Bot 問答

---

## 系統架構
系統主要分為以下模組：

### 前端
- 提供使用者操作介面
- 包含登入、課程瀏覽、影片管理、問答頁面

### 後端
- 負責 API 設計與商業邏輯
- 串接前端、資料庫與 AI 處理流程
- 管理使用者、課程、影片、問答流程

### AI 處理模組
- 語音轉文字（Speech-to-Text）
- Transcript chunking
- Embedding 建立
- 問答檢索與片段定位

### 資料庫 / 基礎設施
- 儲存使用者、課程、影片、片段與問答資料
- 支援向量檢索或相關索引設計
- 提供部署與系統維運基礎
