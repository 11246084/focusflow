## 11-1 系統元件與安裝

系統包含 React 前端、Node.js／Express 後端、Python AI Pipeline 與 MongoDB，服務關係見 [系統架構](../../../../ARCHITECTURE.md)。

本機安裝順序沿用 [專案 README 的快速啟動](../../../../README.md)：準備 Node.js／Python／MongoDB／FFmpeg，安裝 backend 依賴、設定環境，再安裝前端及 Pipeline。完整指令維持於原文件，避免多份版本。

開發啟動指令（從專案根目錄，於不同終端執行；需先完成原 README 的設定）：

```powershell
cd backend
npm.cmd run dev
```

```powershell
cd frontend/focus-flow
npm.cmd run dev
```
