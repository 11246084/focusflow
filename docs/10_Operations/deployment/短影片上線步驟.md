# 短影片上線步驟

這份文件說明把教師短影片（原片剪輯與數位分身）開到正式站給教師試用要做的事，依序是：上線前要先決定的事、VM 後端設定、渲染 worker、部署後驗證、出問題時關閉。功能進度與驗證紀錄只看[目前狀態](../../current-status.md)；連線與 nginx 問題看[部署與連線排錯](部署與連線排錯.md)。

## 上線前要先處理

以下幾項需要負責人處理，未完成前功能無法穩定產出短片。

| 項目 | 為什麼需要 | 怎麼確認 |
|---|---|---|
| Gemini 專案花費上限 | 選段、配圖、整體檢查與數位分身腳本都呼叫 Gemini。2026-11-14 實測專案已達每月上限，API 回 429。 | 在 AI Studio 的花費設定調高上限；一支原片剪輯初次生成最多 5 次呼叫，每次修改最多 5 次。調整後在後端執行 `npm run diagnose:gemini -- --probe`，兩步都是 `OK` 才算可用（`--probe` 會送一次約 10 個 token 的生成請求）。 |
| `YOUTUBE_API_KEY` | 學生短片牆要等 Shorts 同步把成品標成可播放；沒有金鑰時同步不啟動，學生永遠看不到。 | 部署後 `/health` 的 `runtime.shortsSync.enabled` 為 `true`，且有最近成功時間。 |
| 渲染 worker 主機 | 成品 MP4 由獨立的 worker 渲染，後端不渲染。 | 管理員建立 worker 金鑰，worker 啟動後能領到工作（見下方「渲染 worker」）。 |
| 部署授權 | 部署由推送 `main` 觸發（`.github/workflows/deploy.yml`）。 | 負責人確認後把 `dev` 合併到 `main`。 |

## VM 後端設定

在 VM 的後端環境設定（`.env`，不進 Git）加上或確認以下值；金鑰只放在這裡，不寫進文件或 JSON。

| 設定 | 值 |
|---|---|
| `SHORT_SCRIPT_AUTOMATION_ENABLED` | `true`。關閉時整組短影片 API 回 404，前端顯示「目前未開放」。 |
| `RECUT_RUNTIME_CONFIG_PATH` | runtime JSON 的絕對路徑（見下方範例），檔名不可含 `credentials`。 |
| `GEMINI_API_KEY` | 已調高花費上限的專案金鑰；runtime JSON 的 `geminiApiKeyEnv` 指向這個名稱。 |
| `RECUT_GEMINI_MODEL` | 選填；未填沿用 `GEMINI_CHAT_MODEL`。必須列在 runtime JSON 的 `allowedGeminiModels`。 |
| `YOUTUBE_UPLOAD_ENABLED` 與 YouTube OAuth 三個值 | 成品要先以不公開連結上傳，教師才能觀看與核准。 |
| `YOUTUBE_API_KEY` | Shorts 同步用，見上表。 |

runtime JSON 範例（Linux 路徑；`media` 的每個路徑都必須是 VM 上已存在的檔案或目錄）：

```json
{
  "schemaVersion": 1,
  "modelCallsEnabled": true,
  "geminiApiKeyEnv": "GEMINI_API_KEY",
  "allowedGeminiModels": ["gemini-3.5-flash"],
  "maxOutputTokens": 8192,
  "thinkingLevel": "LOW",
  "codeCardsEnabled": false,
  "workspaceRoot": "/opt/recut-runtime/workspaces",
  "media": {
    "allowedRoot": "/opt/focusflow/backend/uploads",
    "ffmpeg": "/usr/bin/ffmpeg",
    "ffprobe": "/usr/bin/ffprobe",
    "python": "/opt/focusflow/STT_Whisper/.venv/bin/python",
    "transcriber": "/opt/focusflow/short_render/src/align/transcribe_words.py",
    "asrModel": "/opt/recut-models/faster-whisper-small"
  }
}
```

- `python` 填虛擬環境裡的直譯器路徑（例如 `.venv/bin/python`），要能 `import faster_whisper`。安裝依 `STT_Whisper/requirements.txt`，其中 PyAV 限制在 19 版以前：faster-whisper 1.2.x 搭配 PyAV 19 會在開檔時失敗，辨識整段失敗。
- `asrModel` 是事先下載好的 faster-whisper 模型目錄（例如 Hugging Face 的 `Systran/faster-whisper-small`）。後端以離線模式執行，不會自動下載模型，缺模型時生成會失敗。
- `allowedRoot` 必須包含教師上傳的原片目錄（`UPLOAD_DIR`）；原片不在這個目錄就無法剪輯。
- 後端產生講稿時會載入 `short_render` 的施工單模組；部署流程會在 `/opt/focusflow/short_render` 執行 `npm ci --omit=dev --ignore-scripts` 並確認模組載得起來（VM 不渲染，不下載瀏覽器）。少了這一步，`/health` 會顯示 `hostStatus: adaptersInvalid`。
- 改完設定後 `pm2 restart focusflow-backend --update-env`，啟動 log 會印 `[recut] host runtime: configured`；其他值表示設定有缺，見下方驗證。

## 渲染 worker

worker 是另一台機器（或明確允許的 VM）上的常駐程式，向後端領已核准的工作、下載原片、渲染並檢查 MP4 後傳回。設定與限制見 [short_render 的 RC7 worker 說明](../../../short_render/README.md#rc7-常駐-worker)，重點：

1. 安裝 Node.js 22.23.4 以上的 22 版，在 `short_render` 執行 `npm ci`。
2. 準備 chrome-headless-shell、FFmpeg／ffprobe，以及 Noto Sans TC 可變字型檔（`NotoSansTC-VF.ttf`，Google Fonts 的 `NotoSansTC[wght].ttf`）。
3. 管理員在後台建立 worker 金鑰（只顯示一次），以環境變數 `RECUT_WORKER_KEY` 提供給 worker；不要放在命令列、設定檔或 Git。
4. 建立本機設定檔（`backendUrl` 非 localhost 時必須是 HTTPS），先用 `node bin/recut-worker.js --config <設定檔> --once` 試一支，再改成常駐。
5. 在 VM 上執行時，設定檔要 `hostKind: 'vm'` 並明確 `enableVmRender: true`，否則 worker 不領工作。

worker 的品質檢查（720×1280、30fps、長度、黑畫面、靜音、-16 LUFS±2、真峰值 ≤ -1.5 dBTP、字型）全部通過才傳回；單聲道原片與峰值受限的原片已在 2026-11-14 以真實渲染驗證可通過。

## 部署後驗證

1. `GET /health`：
   - `runtime.recut.ready` 為 `true`。為 `false` 時看 `hostStatus` 與 `missing`：`runtimeConfigMissing` 是沒設 `RECUT_RUNTIME_CONFIG_PATH`，`pathsInvalid` 是 JSON 裡有路徑不存在，`providerKeyMissing` 是金鑰變數沒設，`modelNotAllowed` 是模型不在允許清單。
   - `runtime.shortsSync.enabled` 為 `true`。
   - `runtime.youtubeUpload` 的上傳開關為開啟。
2. 用一門測試課程走一次：教師在「短影片製作」選題 → 同意 → 講稿出現 → 核准講稿 → worker 做好成品 → 成品自動上傳 YouTube（不公開）→ 教師核准上架 → 等下一次 Shorts 同步後，學生帳號在短片牆看得到。
3. 數位分身走一次：第一次會要肖像與聲音複製同意 → 腳本 → 傳回影片 → 核准上架。
4. 講稿產生一直失敗、任務錯誤是 `RECUT_MODEL_FAILED` 或 `RECUT_PROVIDER_PERMISSION_DENIED` 時，先執行 `npm run diagnose:gemini -- --probe`：它會分出花費上限、速率限制、免費額度、金鑰無效、API 未啟用、模型不存在、服務異常或連線問題，並說明處理方式，不會印出金鑰。
5. 失敗時：講稿產生失敗看任務錯誤代碼；成品做不出來看 worker 輸出的 `code`（例如 `RECUT_TEXT_OVERFLOW` 要改講稿，`RECUT_RENDER_CHECK_FAILED` 看 render job 的 `checks` 數值）。

## 出問題時關閉

把 `SHORT_SCRIPT_AUTOMATION_ENABLED` 改成 `false` 後 `pm2 restart focusflow-backend --update-env`：短影片 API 一律回 404、前端顯示「目前未開放」，不影響問答與其他功能。已上架的短片仍在學生牆；要下架個別短片，目前只能由教師在「短影片管理」撤回授課內容同意並勾選要下架的短片。

例：`/health` 顯示 `ready: false`、`missing: ["host.pathsInvalid"]` → 檢查 runtime JSON 的 `media` 路徑在 VM 上是否都存在 → 修正後重啟 → 再看一次 `/health`。
