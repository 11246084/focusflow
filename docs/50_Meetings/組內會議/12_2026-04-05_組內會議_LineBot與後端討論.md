# 組內會議（LineBot 與後端討論）

- 會議日期: 2026-04-05
- 會議類型: 後端需求討論 / LINE Bot 綁定流程
- 與會者: 鍾百陶, 邱偉豪

## 討論內容

1. LINE Bot 綁定流程的後端協作邊界
  - 文件說明本次需求主要是支援 LINE Bot 綁定流程，重點落在調整既有 model 與補齊必要 collection。
  - 會議中明確區分後端同學與 LINE Bot 實作者的責任範圍，避免改動到不必要的 routes、controllers 與 services。
2. `user.model.js` 欄位調整需求
  - 需新增 `lineUserId`，用來儲存 LINE 綁定後的使用者 ID。
  - 需新增 `lineBindAt`，記錄綁定完成時間。
  - 需新增 `activeCourseId`，表示學生目前在 LINE Bot 選定的課程。
  - 需新增 `lineConversationState`，用來保留目前對話狀態，預設值為 `idle`。
3. `enrollment.model.js` 欄位修改
  - 原本的 `lineState` 設計不符合目前需求，討論後改為較單純的布林欄位 `lineNotify`。
  - `lineNotify` 用來表示該課程是否已開啟 LINE 通知，預設值為 `false`。
4. 環境變數需求
  - `.env.example` 需要新增 `LINE_CHANNEL_ACCESS_TOKEN` 與 `LINE_CHANNEL_SECRET`，供 LINE Bot 綁定流程與 webhook 驗證使用。
5. `app.js` 對 LINE webhook 的處理方式
  - 由於 LINE webhook 驗證需要保留 raw body，會議中明確要求在 `express.json()` 之前，先針對 `/api/v1/line/webhook` 使用 `express.raw({ type: 'application/json' })`。
  - 其他一般 API 則仍維持使用 `express.json()` 與 `express.urlencoded()` 的處理流程。
6. 路由掛載與檔案分工
  - `routes/index.js` 需要掛載 `line.routes.js`。
  - `line.controller.js`、`line.routes.js`、`line.service.js`、`lineSignature.middleware.js` 由 LINE Bot 負責人實作。
  - 與認證、既有後端架構緊密相關的 `auth` 與 `models` 則由後端同學調整。

## 決議事項

1. `user.model.js` 必須新增 `lineUserId`、`lineBindAt`、`activeCourseId`、`lineConversationState` 四個欄位，以支撐 LINE 綁定與課程切換流程。
2. `enrollment.model.js` 中原有的 `lineState` 改為 `lineNotify: Boolean`，並以 `false` 作為預設值。
3. `.env.example` 補上 `LINE_CHANNEL_ACCESS_TOKEN` 與 `LINE_CHANNEL_SECRET`，作為必要設定項。
4. `app.js` 必須改為在 LINE webhook 路徑下先讀 raw body，再處理一般 JSON middleware。
5. `routes/index.js` 需正式掛載 `line.routes.js`，讓 `/api/v1/line/*` 相關端點可被正確註冊。
6. 開發工作依責任拆分：後端同學負責 model、auth 與主程式掛載，LINE Bot 負責人負責 line 相關 controller、route、service 與 middleware。

## 後續行動項目

1. 更新 `user.model.js`，加入 LINE 綁定與課程狀態相關欄位。
2. 更新 `enrollment.model.js`，將 `lineState` 改為 `lineNotify` 布林欄位。
3. 更新 `.env.example`，補齊 LINE Channel 相關環境變數。
4. 調整 `app.js` middleware 順序，確保 `/api/v1/line/webhook` 可正確驗證簽章。
5. 在 `routes/index.js` 掛載 `line.routes.js`。
6. 依分工補齊 `line.controller.js`、`line.routes.js`、`line.service.js` 與 `lineSignature.middleware.js`。
