- Git `1157e3d`（2026-08-09）為 Parent stable contract 遷移，證據不足以宣稱六支 Leaf 已重算成 stable。現行穩定版程式與 Atlas metadata 的缺口見 [前輪診斷](2026-11-10-atlas-diagnostics.md)。

## 本機測試

使用 Node 22.23.4、Python 3.11.9，測試所用 SDK 與 repository 均為替身。

```powershell
node --test backend/tests/multimodal-diagnostics.script.test.js backend/tests/atlas-multimodal-adapter.service.test.js backend/tests/rank-fusion.service.test.js backend/tests/multimodal-retrieval.service.test.js
STT_Whisper\.venv\Scripts\python.exe -m unittest discover -s STT_Whisper/tests -p test_gemini_multimodal_adapter.py -v
STT_Whisper\.venv\Scripts\python.exe -m unittest discover -s STT_Whisper/tests -p test_segment_media_embedding.py -v
STT_Whisper\.venv\Scripts\python.exe -m unittest discover -s STT_Whisper/tests -p test_plan_multimodal_validation.py -v
```

Node 20 項，Python 17 項。涵蓋模型／維度／輸入格式、費用與次數預留、重試／遮蔽、續跑、同一帳本跨輸出控費、Atlas 路徑／權限／契約檢查、三路 RRF、降級與 MVD CLI。

真實六份切片另送入 Fake SDK 進行完整媒體 adapter 驗證。過程修正 1 fps 畫面時長量化造成的拒絕，原始引用時間保持不變，補上獨立回歸測試。
