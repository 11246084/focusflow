# 2026 全國大專院校產學創新實作競賽報名文件

這裡存放 FocusFlow AI 報名 D. 人工智慧及其應用（第四組）的文件。請先依下方補件與送件檢查確認名單、補齊個資並完成親簽，再製作 RAR 上傳；專案功能狀態仍以[狀態正本](../../current-status.md)為準。

| 附件 | 用法 |
|---|---|
| [附件一：報名表](送件版/附件一_報名表.doc) | 直接補填個資並儲存，送件使用同一份 DOC |
| [附件二：組隊成員說明書](送件版/附件二_組隊成員說明書.doc) | 確認成員及分工，送件使用同一份 DOC |
| [附件三：作品說明書](送件版/附件三_作品說明書.doc) | 審閱及修改內容，送件使用同一份 DOC |
| [附件四：參賽與個資同意書](送件版/附件四_參賽與個資同意書_待親簽.docx) | 確認資料後列印親簽，掃描為 PDF 送件；此 Word 是簽署用原稿 |
| [附件五：作品摘要](送件版/附件五_作品摘要.docx) | 審閱及修改摘要，送件使用同一份 DOCX |

例：直接補齊附件一 → 全體親簽附件四並掃描 → 選取附件一、二、三、五及已簽署的附件四 PDF → 以確認後的隊名建立 RAR → 線上報名上傳。不要將附件四的待親簽 Word 或補件說明一起打包。

需要核對表格時，請查看[官方空白表格](官方空白表格/)；本組附件放在 `送件版/`，空白表格獨立保存。

官網：[競賽辦法](https://eedept.ncue.edu.tw/innovation2026/intro.html)、[報名專區](https://eedept.ncue.edu.tw/innovation2026/join.html)。截止時間為 2026-10-22 23:59，送件前請再次查看公告。
