- 同步 OpenAPI、`backend/.env.example`、錯誤碼表、資料表清單與 decisions.md、說明頁。
- 行為變更：已綁定的學生不能再用舊綁定碼直接換 LINE，要先解除綁定；同一個 LINE 綁到別的帳號時改成拒絕。`ask-limits.routes.test.js`、`line.routes.test.js`、`mvp.acceptance.test.js` 原本依賴舊行為，已配合修改。
